# 登录条款资源

登录页从本目录读取 UTF-8 纯文本：

- `agreement.txt`：经确认的用户协议。
- `privacy.txt`：经确认的隐私政策。
- `minors.txt`：经确认的未成年人个人信息保护规则。

当前仓库尚未提供正式正文，因此不放置模拟条款。缺失文件、空文本、非纯文本响应或网络故障时，页面显示“条款正文暂未提供或无法读取”，允许重新读取；不会将站点 HTML 回退页显示成协议。

补齐批准的正文后，静态服务器应以 `text/plain`（建议 UTF-8）响应，随前端构建部署。条款内容由项目负责人确认，不能将测试脚本中的隔离示例作为正式文件发布。
