# 极窄只读观察：原版认证页字段的**交互类型**（Round 319）

> 依据：审核 66 明确要求的**一次**极窄观察，并给了逐字协议与停止条件。
> 方法：MuMu + 原版 `com.kairuotu.campus`，**只读**：`input tap`（纯导航）+ `uiautomator dump`（含 bounds）
> ＋ `dumpsys input_method`（判键盘）＋ `dumpsys window`（判是否换页）。
> ⚠️ 全程**未选择任何值**、**未提交**、**未改任何持久状态**。

---

## 一、审核给的协议（我逐条照做）

```
只做：
  进入认证页
  → dump 确认当前页和目标行
  → 点「所在学院」
  → 观察是否出现 picker / keyboard / 新页面
  → **不选择任何值**
  → Back / Cancel
  → **确认没有持久状态改变**
⚠️ 如果这一条已经足以看出**三个空字段共享同一种交互模型**，就停止；
   **不要**继续把学院、专业、年级全部逐项考古。
```

## 二、观察结果

### 2.1 认证页基线（`dump` 实测，与 Round 318 一致）
```
填写认证信息 ／ 就读学校 = 北京交通大学 ／ 所在学院 ／ 就读专业 ／ 当前年级 ／ 下一步
可点击的「行」节点（clickable=true）：
  [132,583][948,735]   行1 就读学校
  [132,779][948,931]   行2 所在学院
  [132,975][948,1127]  行3 就读专业
  [132,1171][948,1323] 行4 当前年级
  [293,1411][787,1543] 「下一步」按钮
```

### 2.2 ⭐ 点「所在学院」→ **picker**（不是输入框、也不是新页面）
```
出现：["取消","所在学院","确认","在职专业学位中心","软件学院","语言与传播学院",
       "网络空间安全学院","威海国际学院/威海校区","没有我的学院？"]
  mInputShown = **false**     ← **没有键盘**
  同窗口（**没有**换 Activity/新页面）
```
⇒ **「所在学院」= 列表选择器（picker）**：面板内有「取消 / 确认」+ 一列**学院名** + 「没有我的学院？」入口。
⭐ 顺带获得一条**数据事实**：原版给出的学院名是**北京交通大学的真实学院**
（在职专业学位中心 / 软件学院 / 语言与传播学院 / 网络空间安全学院 / 威海国际学院·威海校区 …）。
⚠️ 我们**没有**这些实体（我们只 seed 了学校 + 3 个校区）⇒ 记为能力/数据缺口，**不**据此去编造。

### 2.3 ⚠️ 点「就读专业」→ **无可见反应**（并已排除"点空了"）
```
点击后 dump：["填写认证信息","就读学校","北京交通大学","所在学院","就读专业","当前年级","下一步"]
  —— 与点击前**逐字相同**；无「取消/确认」、无键盘（mInputShown=false）、无新页面
```
**我先排除了"我点空了"这个可能**（因为那会把"没反应"误判成"没有 picker"）：
```
「就读专业」标签 bounds = [187,1030][865,1072] ⇒ 中心 (526,1051)
行3 可点击 bounds = [132,975][948,1127]       ⇒ (526,1051) **落在行内** ✓
（对照：「所在学院」中心 (526,855) 也落在行2 [132,779][948,931] 内 ✓ ⇒ 两次点击方式一致）
⇒ 坐标没问题 ⇒ **就读专业确实没有弹出任何东西**。
```

### 2.4 ⚠️ 为什么**不能**进一步判定「就读专业」的交互模型（而我没去冒险）
```
最合理的假设是：**专业列表依赖已选学院**（未选学院时点专业无反应）——
这是真实 app 里很常见的行为，也能解释 2.3 的现象。
⚠️ 但**验证它必须先选择一个学院**，而审核协议明确要求"**不选择任何值**"，
   且只读约束下我**不**对他人生产界面做"填表"类动作。
⇒ 所以这里**不**给出结论，只给出**假设**，并把该项记为 NOT_EVALUATED。
```

### 2.5 ✅ 复核"无持久状态改变"（★ 这一条我第一次**没测到点上**，已重做）
```
第一次的做法（**失败的复核**）：BACK ×2 之后 dump，看到的是 **Me 页/抽屉**（没回到认证页）
   ⇒ `stillEmptyFields:false` ⇒ **那一步等于没验**。
第二次（正确）做法：**重新进入认证页**，与基线**逐字比对**：
   fieldsStillPresent = ["就读学校","所在学院","就读专业","当前年级"]（四个标签都在）
   addedTextsVsBaseline = **[]** ⇒ **verdict: NO CHANGE（与基线逐字一致）**
⇒ 未选择任何值、未留下任何持久变化。
```

## 三、结论（**含不确定标注**，不夸大）

```
VERIFY_FIELD_COLLEGE_INTERACTION:   **picker**（取消/确认 + 学院列表；无键盘；同页）
VERIFY_FIELD_MAJOR_INTERACTION:     **NOT_EVALUATED / 无可见反应**
        （合理假设=依赖已选学院；验证需选值 ⇒ 超出只读观察边界）
VERIFY_FIELD_SHARED_INTERACTION_MODEL: **不予认定**
        —— 观察结果**不支持**"三个空字段共享同一交互模型"这一假设
           （学院 = picker；专业 = 无反应）。按审核的停止条件，我如实记录并停止，
             **不**继续把学院/专业/年级逐项考古。
VERIFY_FIELD_YEAR_INTERACTION:      **NOT_EVALUATED**（按上述停止条件未做）
ORIGINAL_COLLEGE_LIST:              **OBSERVED**（原版列出北交大真实学院名；我们**无**这些实体）
```
