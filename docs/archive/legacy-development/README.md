# 历史开发资料

这里保留早期 M0–M5 的阶段规范、数据模型、实现依据、评审决定和必要测试证据。2026-10-27 从 `docs/pending/` 迁入本目录；代码、脚本和文档中的完整路径引用已同步更新。

这些文档描述当时的开发过程，其中的待办、环境地址、完成状态和对 AI 的指令均属于历史记录，不应当作当前开发计划或操作授权。日常开发和发布请看[当前开发说明](../../public/development-and-deployment.md)。

## 当前分组

- `m0/` 至 `m5/`：阶段计划、工作单、实现分析、验证记录和相关证据。
- `review-log/`：历史评审和工作过程记录。
- 根目录：历史项目计划、实施日志和事故记录等。

## 队友认领与维护

1. 确认自己负责的资料，注明负责人、用途和最近更新日期。
2. 个人分析与草稿移入 `docs/<姓名或统一缩写>/`。
3. 团队正式使用的计划、设计或维护说明整理后移入 `docs/public/`；正式测试用例、报告和必要证据移入 `docs/test/`。
4. 无需共享的资料移入 `docs/local/`；若已被 Git 跟踪，需要单独取消跟踪。
5. 移动时同步更新引用路径，并维护 [文档入口](../../README.md)。需要保留的历史资料可归入对应目录的 `archive/`，标明适用时期。

新增临时输出放在 `docs/local/` 或 `.local/`；正式功能说明整理到 `docs/public/`，不要继续向本目录堆积日常日志。
