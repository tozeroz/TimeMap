# 原版交互清单（逐按钮实测）

> 方法：在 MuMu 上打开原版 app，对每个可点击元素执行「截图 → `adb shell input tap` → 截图 → 比对」，
> 再用视觉模型识别点击后的界面。工具：`tools/probe.ps1`。
>
> **前置条件（重要）**：模拟器的逻辑显示必须处于 `rotation 0`。
> 此前设备是 `rotation 1`（横屏坐标系），截图是竖屏图像，两者需要换轴换算（图像点 (px,py) ↔ 逻辑点 (py, 1080−px)），
> 点击极易点偏；`wm set-user-rotation` 在本机不可用，用 `settings put system accelerometer_rotation 0`
> + `settings put system user_rotation 0` 后才落到 rotation 0，此时截图坐标 = 点击坐标。

## 一、校园广场（`campusx://trident`，trident 默认 tab）

| 元素 | 坐标 | 实测结果 |
|---|---|---|
| 顶部「校园广场 ▼」 | (110, 125) | **展开学校搜索面板**：出现圆角搜索框，提示语「搜索其他学校」，下方是学校列表；信息流与底部导航不被遮挡 |
| 右上角聊天图标 | (1005, 100) | 进入聊天页（`聊天` / 分享我的校园卡 / 邀请同学 / 更多同学） |
| 卡片作者头像 | (70, 290) | **进入 TA 的主页**（有加载过程） |
| 卡片图片 | (270, 650) | 进入动态详情（含「08-30」日期、「留下我的评论」评论入口） |
| 底部「自定义名称6」 | (235, 1780) | 个人主页 |
| 底部「校园」 | (390, 1780) | 校园广场 |
| 底部「地图」 | (590, 1780) | 地图页 |
| 右下角「+」 | (950, 1780) | **进入发布页**（不是纯相机，见下） |

**卡片结构**：作者行（头像 + 昵称）在**图片上方**，正文压在图片底部；瀑布流双列、高度错落、卡片间为浅灰底。

## 二、地图页（点底部「地图」）

> 注意：deep link `campusx://map` **不会**切到地图 tab（它打开的是上次停留的 tab），必须点底部导航。

| 元素 | 坐标 | 实测结果 |
|---|---|---|
| 拖拽（swipe 800,1200 → 300,1200） | — | ✅ **地图跟随平移** |
| 位置文字 | (300, 150) | 「**北京交通大学（校本部）**」（不是「北京市·海淀区」） |
| 右上角图标 | (1000, 130) | 有控件 |
| 右下角控件 | (1000, 1690) | 定位/指南针类控件 |
| 右下角「+」 | (965, 1800) | 发布 |

**标记形态**：**照片卡片 + 彩色图钉 + 地点名**（例：红色图钉「阳光操场」、黄色图钉「达美乐比萨(广州萝岗万达广场)」），
点击进入对应动态。地图中心还有**蓝色定位点 + 方向扇形**。左下角有腾讯地图水印。
首次进入有阻断式弹窗「授权地理位置 / 在地图上，标记属于你的校园生活 / 暂时不要·授权」。

## 四、发布页（点右下角「+」）

| 元素 | 实测结果 |
|---|---|
| 顶部定位标签 | 「富春山居千人宴会厅」样式的地点标签（可移除） |
| 中部 | **图文编辑器**：输入框提示语「说点什么...」、图片缩略图、**字体选择（经典/黑体…）** |
| 底部 | 模式切换「语音 / 拍摄 / 文字」+ 快门/发布按钮 |

即：发布页是**三模式合成器**（相机取景只是「拍摄」模式），不是纯相机页。
