# 实训项目入口首次提示

维护人：前端模块协作者；最近更新：2026-11-20；适用模块：活动列表页。

## 目的与范围

现有「校园活动」标题兼作内容模式切换入口，用户容易忽略下拉箭头，无法发现「实训项目」。保留现有标题、下拉菜单、筛选和列表，增加一次可关闭的入口提示，不改成双标签导航，不新增服务端接口。

## 展示与交互

- 本机首次进入校园活动列表时，在标题左下方展示深蓝底、白字的小气泡，尖角向上指向标题。文案：**点击这里，切换实训项目**。
- 标题左侧没有足够空间，因此气泡与标题左边缘对齐。显示期间为气泡预留垂直空间，避免遮挡副标题和筛选；关闭后恢复原布局。
- 点击标题或通过方向键打开下拉菜单时，提示消失，原菜单正常展开，可继续选择「实训项目」。
- 点击气泡关闭按钮或按 Esc 也会关闭提示；关闭按钮支持键盘操作，触控区域至少 44 × 44px。关闭按钮操作后焦点返回标题。
- 提示不自动抢焦点、不设置倒计时、不添加全屏遮罩，不阻断筛选、刷新或浏览。
- 直接进入实训项目页不显示提示。尚未关闭提示就离开活动页，返回后仍可显示，直到用户关闭或打开过切换菜单。

## 记忆规则与异常处理

使用 `localStorage` 键 `timemap.activity-mode-hint.dismissed.v1`，值为 `1` 表示已关闭或操作过入口。刷新、离开再返回、重新启动后不再显示。按当前浏览器/WebView 本机环境记录，与账号无关，退出登录不重置；清理站点数据后可以重新显示。

存储读取或写入失败时，不影响活动页与菜单：当前 JavaScript 会话用内存记录关闭状态；重新启动后可能再次提示。无需登录、网络请求或数据库迁移。

## 实现位置

- `app/src/components/ActivityModeTitle.tsx`：显示条件、关闭状态、持久化、键盘行为及原下拉菜单。
- `app/src/screens/trainingprojects.css`：共用标题与提示气泡样式，复用现有颜色、圆角和阴影变量。

## 验收

1. 清除上述存储键后进入 `/#/activities`，提示显示，原下拉菜单保持关闭。
2. 点击关闭按钮后刷新、切换页面再返回，提示不再显示，标题仍可打开菜单。
3. 新环境点击标题，提示关闭、菜单展开；选择实训项目可正确切换，返回校园活动不再提示。
4. 新环境使用 Tab 和方向键可打开菜单；Esc 可关闭提示或菜单，焦点可继续操作，无键盘陷阱。
5. 直接进入 `/#/activities?mode=projects` 不显示；未操作切换入口就回校园活动仍可显示。
6. 在 320、390、430px 和桌面宽度下，气泡不横向溢出，关闭按钮可触达，不遮挡筛选和刷新。
7. 模拟存储读写抛错后，页面正常展示；关闭后同一会话内再次进入不重复显示。

开发调试时可在浏览器控制台执行 `localStorage.removeItem('timemap.activity-mode-hint.dismissed.v1')` 后刷新，重新查看提示。
