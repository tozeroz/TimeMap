# 时光坐标 UI 设计规范

适用模块：TimeMap 前端；维护人：前端模块协作者；最近更新：2026-10-31。

面向校园地点记录、图片发布和帖子浏览，界面以温暖、清晰、安静为方向。主要操作使用暖橙，内容使用深蓝文字；用照片和地点承载记忆感，手写字体仅用于少量装饰。

## 代码位置与协作

- `app/src/styles/tokens.css`：颜色、字号、间距、圆角、动效变量的唯一维护入口。
- `app/src/styles/global.css`：基础重置、字体继承、键盘焦点和减少动效设置。
- `app/src/components/Button.tsx`、`button.css`：公共按钮及加载、禁用状态。
- `app/src/screens/*.css`：页面布局和特有样式。发布页为本轮迁移样板。
- 新增样式先查已有变量和组件。修改全局变量需检查相关页面，页面专属样式使用页面类名前缀。

沿用现有 `--c-*`、`--r-*`、`--f-*` 命名，不新增一套同义变量。已有页面含硬编码样式，应随页面改版逐步迁移；扫码和媒体预览保留深色表面，桌面外围背景与原生安全区继续由 Shell 管理。

## 颜色

| 用途 | 变量 | 色值 |
| --- | --- | --- |
| 页面背景 | `--c-bg` | `#FAF8F3` |
| 弹窗、输入等表面 | `--c-surface` | `#FFFFFF` |
| 低层次背景 | `--c-surface-sunken` | `#F0EEE8` |
| 主要文字 | `--c-text` | `#192D42` |
| 辅助说明 | `--c-text-2` | `#606D7B` |
| 第三级文字 | `--c-text-3` | `#606D7B` |
| 占位文字 | `--c-placeholder` | `#606D7B` |
| 品牌装饰橙 | `--c-brand` | `#ED6536` |
| 主要操作、小字强调 | `--c-primary` | `#C44B22` |
| 橙色浅底 | `--c-primary-soft` | `#FFF0E8` |
| 少量地图、装饰绿 | `--c-sage` | `#829579` |
| 分隔线 | `--c-divider` | `#E5E3DE` |
| 输入框及次按钮边界 | `--c-input-border` | `#82909B` |
| 错误、危险操作 | `--c-danger` | `#C43D3D` |

品牌橙对白字对比度约 3.22:1，不能直接用于普通字号的白字按钮；操作橙对白字约 4.80:1。普通文字目标至少 4.5:1，实际按相邻背景复核。辅助文字、占位文字统一加深到 `#606D7B`，兼顾白底和米白底。第三级变量暂时与辅助文字同值，保留语义便于后续调整。占位文字不替代输入标签。绿色不承担小字信息。现有 `--c-accent` 和 `--c-accent-soft` 保留蓝色链接与气泡用途，不直接替换成绿色。

参考：[W3C 文字对比度说明](https://www.w3.org/WAI/WCAG21/Understanding/contrast-minimum)。

## 按钮

| 类型 | 用途 | 样式 |
| --- | --- | --- |
| `primary` | 发布、保存、确认 | 深橙底、白字 |
| `secondary` | 取消、备选操作 | 透明底、深蓝字、描边 |
| `text` | 添加文字等轻量操作 | 无底色、深橙字，可传入图标 |
| `danger` | 删除、放弃编辑、退出登录 | 红字，名称明确说明后果 |

默认最小高度 44px，圆角 12px；紧凑按钮视觉高度 36px、胶囊圆角，需为其补足实际点击区域。图标按钮点击区域至少 44×44px。高度使用最小值，允许长标签换行及文字放大。加载保留原标签占位、显示进度图标、提供读屏状态并禁用重复点击；禁用使用专用灰色，不单纯降低整个按钮透明度。

```tsx
<Button loading={saving} disabled={!valid} onClick={save}>保存</Button>
<Button variant="secondary" onClick={cancel}>取消</Button>
<Button variant="text" icon={<AddIcon />} onClick={add}>添加文字</Button>
```

## 字体、间距、容器

系统字体；页面标题 24px、导航标题 17px、正文与输入 16px、辅助说明 13–14px。正文行高约 1.6，按钮与导航另设紧凑行高。旧版 `--f-tiny` 保留兼容，不用于新增重要说明。

页面左右边距 20px；间距档位 4、8、12、16、24、32px，分别使用 `--space-1/2/3/4/6/8`。图片圆角 16px、弹出面板顶部圆角 24px。

发布表单使用留白和分隔线；帖子流按内容需要使用卡片；地点详情按章节组织，避免字段外反复套卡片。输入框、按钮可用独立白色表面。320px 窄屏到桌面居中画布都应可用，保留原生安全区，长文字和操作组允许换行。

## 状态与动效

动效以 150–250ms 为主。按钮按下轻微缩小、图片载入淡入、底部面板滑入并淡入遮罩；输入和浏览过程不加无意义进场动画。展开动画需按实际布局实现，不能假设 `height: auto` 总能直接过渡。尊重 `prefers-reduced-motion`。

- 加载：保留布局与反馈，禁止重复提交；可编辑区域按实际业务处理。
- 空内容：说明缺少什么，提供选择地点、添加内容等下一步。
- 错误：保留用户内容，显示原因及重试入口，不只依赖颜色。
- 部分可用：如地点加载失败，正文仍保留，可重试地点请求。
- 成功：发布后进入对应地图记录；保存本地草稿后退出。
- 权限：相机、存储或登录失败需说明恢复路径，不静默失败。

键盘焦点必须可见；表单保留显式标签、字数与错误关联。改版验收需查看窄屏与桌面实际渲染，覆盖禁用、加载、错误、长文和减少动效；未实测状态如实记录。
