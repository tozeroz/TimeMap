## 二、怎么装

**方式 A：手机浏览器打开（最快）**
1. 手机浏览器访问 `http://8.148.156.146/download/campus-demo-1.0.apk`
2. 系统会提示"是否允许安装未知应用" ⇒ 允许（因为这是 debug 签名，不是应用商店来源）
3. 装完打开即用

**方式 B：用数据线 + adb**
```
adb install -r "G:\demo map\campus-demo-1.0.apk"
```

⚠️ **注意**：这是 **debug 签名**的 APK（`CN=Android Debug`）。
- 这不影响功能，但首次安装必须允许"未知来源"。
- 以后如果换成正式签名发布，必须先卸载这个 debug 版（签名不同无法覆盖安装）。

## 三、怎么登录（⭐ 这一步容易卡住）

本项目**没有接入短信通道**，验证码不会发到手机。这是设计如此（demo 环境），
后端把验证码投递到一个 **dev sink**（服务器上的一个目录）。

**数据库里实际存在的 3 个账号**（实测查询所得）：

| 手机号 | handle | 昵称 |
|---|---|---|
| `+8613800000001` | anmoss | anmoss |
| `+8613800000002` | lemy | Lemy |
| `+8613800000003` | azur | Azur冰弦 |

**取码步骤**（在电脑上执行，手机上也照样输入同一个号码）：
```powershell
# 1) 在手机上输入 +8613800000001，点"获取验证码"
# 2) 在电脑上运行：
ssh -i "G:\demo map\TimeMap.pem" root@8.148.156.146 'bash /srv/campus/tools/get-login-code.sh +8613800000001'
#    脚本会打印出 6 位验证码（例如 584537），并顺手验证它确实能换到 token
# 3) 把验证码输到手机上
```
> ✅ 已实测：请求验证码 → 从 sink 读出 `584537` → 用它成功换到 token
>    （返回 `user.handle = anmoss`）。验证码**5 分钟有效**。
> ✅ 脚本放在 `/srv/campus/tools/get-login-code.sh`（**持久位置**，重启不丢）；
>    对 lemy 那个号也实测通过。
> 脚本源码在仓库里：`tools/get-login-code.sh`

⚠️ 你可以用**任意中国大陆手机号**请求验证码，但要能登录必须用上面 3 个已存在的账号
（其它号码能拿到码，但库里没有对应用户）。

## 四、真机 vs 模拟器的差异（要留意）

1. **HTTPS 证书**：APK 内置了我们自建私有 CA 的公钥证书
   （`app/android/app/src/main/res/raw/campus_demo_ca.crt`，由
   `network_security_config.xml` 的 `trust-anchors` 引用）
   ⇒ **App 自己访问 `https://8.148.156.146` 不会报证书错误**，这一点与模拟器一致。
   ⚠️ 但如果你用**手机浏览器**打开 `https://8.148.156.146`，浏览器会警告证书不受信任
   （浏览器不读 App 的 trust-anchors）——这是预期的，用 http 那个下载链接即可。

2. **摄像头相关**：
   - 发布页"拍摄"、扫码页取景都需要**摄像头权限**（首次会弹窗，允许即可）。
   - 扫码是**真实取景 + 真实 QR 解码**，理论上真机扫真实二维码就能用。
     ⚠️ 但"摄像头光学拍到物理二维码"这一步**从未验证过**（本机模拟器是内置摄像头、
     拍不到自己屏幕）⇒ 你在真机上扫一次，正好补上这段 smoke test。
   - 注意：**只承诺 QR 码**；条形码（EAN/Code128）是否支持**未评估**。

3. **App 内「版本信息」页会显示 v1.0**，并提示"发现新版本 v1.1"。
   ⚠️ **建议先别点「立即更新」**：那个 `campus-demo-1.1.apk` 是为验证更新流程而构建的
   **演示产物**（构建时间早于之后的两处修复），并不是一个"更好的新版本"。
   真要在真机上验证更新流程是可以的（它会调起系统浏览器下载），但拿到的不是最新代码。

## 五、如果装上有问题，先这样排查

| 现象 | 先看这个 |
|---|---|
| 打开就白屏 | 用 `adb logcat` 看 WebView 报错；或确认后端可达：浏览器开 `http://8.148.156.146/api/health` |
| 登录时"网络错误" | 确认手机能访问 `https://8.148.156.146/api/ready`（应返回 200） |
| 图片不显示 | 图片走 `/media/<key>`（公开静态）；确认手机能直接打开那个 URL |
| 提示证书错误 | 说明装的不是这个 APK（我们这份内置了 CA），或 APK 被替换过 —— 对比上面的 sha256 |
