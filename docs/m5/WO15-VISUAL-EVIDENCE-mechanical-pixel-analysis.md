# WO#15 视觉证据：用**机械像素分析**替代不可用的视觉通道

> 时间：2026-09-22 10:08｜Round 266
> 触发：`MAP_PIN_COLOR_SEMANTICS_CONFORMANCE` ／ `ORIGINAL_MAP_MARKER_CONFORMANCE` ／
> `OFFLINE_MAP_PROJECTION_CONFORMANCE` 三项一直记 `NOT_EVALUATED`，
> 原因是**唯一的视觉通道不可用**（本会话 `vision` 工具两次调用返回空）。
> 本文件记录我为此找到的**替代通道**及其产出。

## 〇、为什么"看图"不等于"必须让模型描述"

```
我一直把"看基线截图"等同于"调用 vision 模型"。但**很多断言需要的只是可测量的量**：
   某区域有几个高饱和色块 / 它们的色相族 / 位置 / 尺寸……
这些可以**机械地**从 PNG 像素里算出来，而且：
  · 可复现（同一脚本同一阈值 → 同一结果）
  · 可复核（审阅者能自己跑一遍）
  · **无主观性**（不像"模型说它看到红色图钉"）
⇒ 在新断言难以量化的场景，机械测量往往**比视觉描述更硬**；而在需要语义判断的场景
  （"红色代表什么"），机械测量**给不出答案，也不该假装给**。
```

## 一、方法与工具

`scripts/m5/analyze-baseline-pixels.py`（本机 Python 3.14 + **PIL 12.3.0** 已具备，无需联网装包）：
```
① 读 PNG，输出尺寸
② 统计**高饱和像素**的**色相直方图**
   （饱和 S≥90、亮度 60≤V≤250 —— 排除近黑阴影与近白高光；
     地图底图多为灰/米/浅绿，饱和度低，故"最饱和的东西"通常就是标记/卡片）
③ 对其做**连通域分析**：色块个数、bbox、中心、平均 RGB/HSV
④ 可 `--crop x,y,w,h` 只分析指定区域
⑤ 输出 JSON（含**方法学阈值**，因为换阈值结果会变）
⚠️ 边界：**只测量颜色与几何，不解释语义；也不认字**（读不出地名文本）
```

## 四、⭐⭐ 必须声明的**混淆变量**（我差点做错归因）

我一开始想说："`normal.png` 的地图区**没有**标记，而 `map-pins.png` 有"。
**查了混淆变量后发现这个说法站不住**：

```
地图主体区域（0,300)–(1080,1700) 的**量化色丰富度**（量化到 32 级，步长 4 采样）：
   normal.png          ：**10 种**量化色；**79.85% 是同一种灰 (224,224,224)**
                         → 高度均一 ⇒ **地图很可能根本没加载**
   recovered-m3-map-pins.png：**145 种**量化色，且含 **0.86% 纯黑 (0,0,0)**
                         → 内容丰富（含黑色文字/线条）⇒ **地图已加载**
⇒ **两张图的"地图加载状态"本身就不同**，
   所以它们之间的差异**不能**归因于"有没有标记" —— 加载状态是**混淆变量**。
⇒ 正确说法：我**只能**在 `map-pins.png` 上做测量；
   关于 `normal.png`，**不得**声称"原版当时没有标记"。
```

## 六、这次的方法学收获（值得留在纪律里）

```
**"证据通道不可用"不等于"该事实无法取证"。**
   · 先问"这个断言需要的到底是**语义**还是**可测量的量**"；
     后者可以用机械分析拿到，而且**比模型描述更硬**（可复现、可复核、无主观性）。
   · 但要**严格区分**：测量能支撑"存在红相色块"，**不能**支撑"红色代表某类动态"。
     本文件对两类结论分别给了明确的状态，**没有**把测量当解释。

**并且**：做"两图对比"式的归因之前，**必须先排除混淆变量**。
   本次的混淆变量是"地图加载状态"，它让一个看起来自然的对比结论**完全不成立**。
   （同族教训：本项目此前"零命中"要先用"搜索范围完整"来背书；这里是"差异"要先用"其他变量一致"来背书。）
```
