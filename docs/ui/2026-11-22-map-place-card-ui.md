# 地图下拉面板地点卡片 UI 复刻

日期：2026-11-22。范围：仅点击“拍照打卡”标签后的底部面板卡片布局与点击行为。“全部 / 有图记录 / 最近更新”和校园故事继续使用原来的帖子卡片。

## 设计依据

依据本轮确认的“地点优先”示意图：地点名称在照片上方突出显示，距离作为辅助信息；照片属于地点的展示素材，仍能返回原帖。沿用现有地图、顶部筛选、排序、面板高度、拖拽关闭及重新打开操作。

参考图：[地点优先卡片示意图](assets/map-place-card-reference.png)。其中地图、照片和数字仅作布局参考，不写入业务数据。

## 卡片呈现

1. 同一地点的已加载记录合并成一张地点卡片，以真实 `placeId` 分组，不能仅凭同名合并。地点名称优先取接口中的当前地点名。
2. 顶部为加粗大标题和类型标识，下一行展示真实距离及地点地址；未授权定位或缺少坐标时省略距离，不填示例数字。
3. 中部是横向可滚动的照片/文字记录轨道。图片取公开帖子的原图；纯文字记录沿用广场纸张封面。显示下一张的边缘提示可滑动，每项保留作者与时间，点击进入对应原帖。
4. 展示当前轨道项的位置和总数，这个数量仅表示当前已加载的展示项，不冒充地点全部帖子数量。提供上一项、下一项按钮，兼容键盘和非触屏操作。
5. 下方以当前轨道项的原帖首段作为摘要，不生成未经维护的推荐理由。
6. 底部提供“查看地点”和“相关帖子”入口；前者打开现有地点详情，后者从当前展示项进入原帖浏览。同地点记录持续加载后合并到原卡片。
7. 故事以后仍按帖子展示，不能因为本次地点卡片复刻改变为独立管理员文章。

## 当前数据与本次边界

地点卡片仅在 `filter === 'checkins'` 时使用，不能扩展到默认附近记录或最近更新。普通帖子不因 UI 修改自动成为打卡内容。后续已按用户确认接入管理员维护和分类查询，见[接入方案与验证记录](../zwf/2026-11-22-管理员分类筛选与地图展示接入方案.md#8-本地实现与验证记录)。

“拍照打卡 / 校园故事”分别读取管理员设置的打卡地和人工标记的原帖，尚未维护内容时显示该范围暂无内容。故事复用原帖子卡片，只补充故事标签。

打卡查询按地点分页，同一地点的已选择展示项随地点返回。照片轨道数量是有效展示项数量；底部总数为打卡地点数，不能显示成用户帖子数。

## 视觉与验收

- 白色圆角卡片、深色地点标题、浅色类型标识；与既有面板颜色变量一致。
- 375、390、430 像素及横屏下不产生页面横向溢出，照片轨道独立滚动。
- 地点按钮、照片按钮、轨道切换按钮有可读名称和焦点样式，点击区至少 44 像素；尊重减少动画设置。
- 地图实例、标记、顶部控件和面板关闭行为保持原样。
- 验证同地点分组、照片与文字封面、轨道切换、作者信息与原帖跳转；无定位不编造距离。

## 实施与验证记录

已新增 `MapPlaceCards.tsx` 和独立样式，仅接入“拍照打卡”的可关闭地图底部面板；默认附近记录、最近更新和故事保持原帖子卡片。分类维护另通过迁移 `047_map_curation` 及管理接口实现。

回归以默认附近记录和最近更新仍呈现原帖子卡片为验收重点，同时检查纯文字封面一致性、待整理空态、面板关闭/恢复/拖拽、地图实例和标记不变，以及 375/390/430 像素和横屏无页面横向溢出。测试图片使用布局瓦片，不是正式校园照片。

早先将地点卡片用于普通附近记录的截图不再作为验收依据。接入后的打卡布局见[拍照打卡分类截图](assets/map-checkins-connected-390.png)；截图使用测试夹具，不代表正式数据库已经维护了内容。
