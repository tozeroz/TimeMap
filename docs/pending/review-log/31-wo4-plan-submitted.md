## 二、本轮附带发现的一条候选纪律（已报审，待裁定）

**C6 是"测量对、模型错"的典型**：

```
测量（仍可用）: 原版墨迹外接 ≈ 23 CSS px（在 40 CSS px 盒子里）
解读模型（已错）: "⇒ 字号应 24px"  —— 预设了"原版用字体渲染"
实际:            原版是 ImageView + 随包 webp，**根本不存在字号**
正确重解读:      那 23~24 CSS px 是**图片的显示尺寸**
```

→ 候选纪律：**旧 finding 里"由测量得出的数字"往往仍可用，
   但"由模型得出的参数"可能在模型被推翻后失效。**
   修旧结论时，要**分辨这两类**，不要因为模型错了就把测量一起丢掉，也不要因为测量还在就沿用旧模型。
