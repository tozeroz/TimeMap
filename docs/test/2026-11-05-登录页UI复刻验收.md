# 登录页 UI 复刻验收

日期：2026-11-05。分支：zwf。范围：登录首屏、验证码状态、管理员密码登录与条款阅读容器。设计依据：[登录页复刻方案](../zwf/2026-11-05-登录页UI复刻方案.md)。

## 实施结果

- 按参考图复刻暖白背景、海军蓝标题、时钟图钉 SVG、白色圆形返回按钮、手机号圆角框、橙红胶囊主按钮及绿色协议入口。
- 品牌文字为“北交时光”，主标题为“欢迎回到TimeMap”；正文为“用手机号登录，留住校园里的每段时光”。
- `#/login` 与已有 `#/loginselect` 均使用同一登录组件，避免额外的选择步骤及两页间返回循环。右上角切换管理员密码登录。
- 复用现有发码、验证码验证、管理员认证与会话接口。手机号可编辑/修改；验证码重发、防重复提交、发送方式反馈、错误提示、统一管理员凭据拒绝和登录去向均保留。
- 倒计时按截止时间计算，监听可见性变化，切后台不依赖累计 tick 次数；卸载清理监听与定时器。429 返回的等待秒数（可读取时）同步到按钮。
- 协议默认未选；缺少有效号码或未同意时不发请求。条款点击不改变勾选状态，原生弹窗支持 Escape 和焦点返回；协议容器保留未成年人规则入口。
- 清理旧选择页拼贴样式，所有新样式限定在登录页和条款弹窗，其他页面配色不变。正式网页状态栏仍沿用 Shell 规则。

## 验证

执行：`node tools/checks/login-ui.mjs`。脚本在本地浏览器拦截所有认证接口，所有号码、口令、签名和会话均为隔离样例，不向真实后端发码或登录。

- 320×740、390×844、430×932、1440×900 截图及页面横向溢出检查通过；桌面为现有居中移动端容器。
- 两个入口、品牌及主标题文案、空手机号校验、未勾选不发码。
- 条款缺失、读取重试、用户协议/隐私政策/未成年人规则容器、Escape、焦点返回；点击条款不自动勾选，号码保持。
- 短信通道 503、发送中反馈、SMS 签名与开发投递提示、验证码长度、无效验证码、倒计时到期、重发和修改手机号。
- 管理员凭据错误使用统一提示、服务错误可重试、模式切换清空密码、成功写入模拟会话并进入管理页。
- 学生登录成功进入校园广场；已有活动投稿回跳参数正常消费。429 等待结束可重试。
- 390×430 缩短视口仍可滚动到主按钮；协议字体增大至 18px 时可换行，无横向溢出。减少动画设置下无装饰动画。
- 浏览器无页面 JavaScript 错误；构建通过。lint 无错误，保留仓库现有警告，登录组件无新增警告。
- 正文和背景对比度核对：橙红按钮白字约 5.15:1，副标题约 4.77:1，输入占位文字约 4.64:1，深绿条款链接约 5.42:1。

## 当前限制

- 仓库没有正式批准的协议正文。页面提供真实的缺失提示及重试，未编造条款；需按 [条款资源说明](../../app/public/legal/README.md) 补齐批准的纯文本后随前端部署。
- 未执行真实短信通道或线上身份联调，不以模拟接口通过替代服务端认证验证。
- 软键盘通过缩短视口检查可达性；未执行 Android 真机键盘实测。
- 本轮未修改后端、提交、推送或部署。
