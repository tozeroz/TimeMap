## 本地查看与复验

本次保留的预览地址：[地图首页](http://127.0.0.1:5187/#/map?raster=1)，后端为 3007，仅使用独立本地测试库。

重新建立隔离数据（不会覆盖远程）：

```powershell
node tools/configure-local.mjs
# 若本地 PostgreSQL 未启动，先按 docs/public/local-testing.md 启动 15432 服务。
node --experimental-strip-types tools/checks/campus-places.mjs
npm run build --prefix server
pwsh -File tools/start-campus-preview.ps1
```

启动脚本验证隔离数据库名并显式传递数据库地址，不继承可能指向远程的 DATABASE_URL。端口已占用时应先核对并停止该预览，再启动新测试库，不能仅看到旧接口 ready 就认为新数据已生效。

基础浏览器回归运行 `node tools/checks/campus-map-ui.mjs`。完整照片／提交状态回归需先执行 `node tools/checks/campus-preview-fixtures.mjs` 准备隔离夹具，再运行 `node tools/checks/campus-map-states.mjs`；结束后运行 `node tools/checks/clean-campus-preview-fixtures.mjs` 清除测试帖子与媒体。测试工具均限制在本地专用数据库。

## 前端回退后的排除兼容修复

旧版地图读取 `/api/places` 的 enabled 地点，不识别新版 map_managed。为保证两版前端均遵守排除决定，导入脚本对茅以升坐像、郑振铎铜像、留园同时设置 enabled=false、map_managed=false、allow_posting=false。不会删除地点行或其帖子／照片／活动关联；管理核对列表仍可通过 includeDisabled=1 查看。该修复仅应用到本地预览数据库，远程未写入。
