# 全屏帖子页：UI 与交互检查

日期：2026-11-05

根据用户提供的《时光坐标_全屏帖子页交互说明》和页面参考图实现。使用 ui-ux-pro-max 审视触控热区、手势冲突、焦点管理、安全区和减少动态效果；通用设计系统输出不符合参考图，视觉采用参考图的米白、橄榄绿与暖橙。

## 本轮实现

- 作者固定顶栏、适配完整比例的单张图片、多图序号、正文摘要、地点与固定互动栏。
- 评论底部面板（约 65%）、独立滚动、输入入口自动聚焦；图标入口不聚焦。支持关闭、遮罩、把手下拉与浏览器返回关闭。
- 每帖独立草稿及图片序号；纯文字纸张区域、全文面板和复用现有 PhotoViewer 的缩放预览。
- 横纵方向锁定、滑动阈值、短滑保持原帖，以及键盘方向键切帖。按最新布局要求移除可见的前后切帖按钮与帖子序号。
- 广场、收藏、个人记忆及地点列表提供已加载列表的冻结顺序；单条直接链接仅浏览当前帖。返回来源列表恢复滚动；广场恢复筛选和排序。
- 继续使用真实点赞、收藏、发布评论、删除自己的评论、举报及删除帖子接口。点赞收藏即时反馈，失败恢复，成功采用服务端计数。
- 首版隐藏评论回复与评论点赞操作。既有回复作为单层评论显示，避免已有评论从界面消失。

## 验证结果

`npm run build` 通过；oxlint 无错误，现有页面仍有 effect 相关警告。新建 PostReader、feedBrowse 无 lint 警告。

浏览器在 375×812 与 844×390、减少动态效果开启下检查通过：图片切换、评论面板开关与焦点、草稿保存、空白和超长评论不可发送、预览退出、浏览器返回先关闭面板、前后切帖恢复图片及各自草稿、短滑不切帖、长滑切帖、点赞和收藏失败回滚、评论发送失败保留草稿并恢复输入焦点、无横向溢出、无运行时异常。

浏览器检查使用隔离接口夹具，未向真实服务发布或删除内容。截图位于 `.local/post-reader/`，图片仅为布局测试素材，不是产品预置内容。真实移动键盘和双指手势仍需真机校准。

## 接口边界

本轮未变更服务端和数据库。连续浏览范围为来源已加载列表；没有新增游标分页。评论仍沿用现有完整列表接口，未新增独立分页、提交幂等标识及超时结果核对接口。因此不将本轮视为说明文档全部 18 项的端到端后端验收。

## 紧凑底部布局调整

移除上一条／下一条和帖子位置序号；地点独立放在固定互动栏上方。375×812 与 844×390 浏览器几何检查均通过，标签可见背景到评论输入框的距离为 15px，内容区、地点区域与底部互动栏无重叠；上滑切帖正常。纯文字区域随剩余空间扩展，不再固定为 8 行。

## 桌面滚轮切帖

支持鼠标滚轮与触控板上下滚动：累计 100px 才触发切帖，向下下一条、向上上一条。行／页单位滚轮事件会归一化；横向滚动、Shift 横滚、Ctrl／Meta 缩放不触发切帖。

一次连续手势只切一条；必须停止滚动至少 320ms，且距上次切换至少 750ms 才解除锁定。监听器位于持续挂载的浏览会话层，因此详情加载及新帖挂载不会重置锁。打开评论、全文、更多面板或图片预览时保留前景原有滚动行为，关闭后的惯性尾部也不触发切帖。

桌面浏览器会话首次进入显示“滚动鼠标滚轮切换帖子”，约 3.2 秒后隐藏，成功切帖时提前隐藏。不恢复前后切帖按钮与帖子序号。

验证：生产构建、diff 格式检查通过。隔离浏览器检查通过：原生鼠标滚轮、轻触阈值、超过冷却时间的连续触控板事件仍只切一条、延迟详情加载期间锁保持、反向切换、横滚忽略、行／页单位、评论和全文正常滚动、图片预览隔离、面板关闭后的惯性、末尾不循环、首次提示仅出现一次；无运行时错误。测试不写真实服务。
