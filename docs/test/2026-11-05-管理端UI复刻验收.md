# 管理端 UI 复刻验收

日期：2026-11-05。分支：zwf。范围：管理中心公共头部、六项分类导航及活动管理页。参考：[复刻方案](../zwf/2026-11-05-管理端UI复刻方案.md)。

## 实施内容

- 暖白背景、校园绿按钮、双行管理中心标题、盾牌标识和绿色下划线导航；保留操作记录，窄屏导航可横向滑动。
- 活动页标题、新建按钮、搜索栏、五种状态、地点/日期筛选、数量与刷新、月份日期牌、来源/地点/时间、状态标签、详情/编辑/更多操作。
- 接入既有 POST/PATCH：新建与编辑共用表单，编辑回填并保留封面、主办方等信息，可清空可选字段；按北京时间回填和提交。
- 更多菜单提供取消/恢复及二次确认，成功后重新读取列表；失败保留表单草稿。
- 新弹层采用原生 dialog，支持焦点约束、Escape 关闭和关闭后返回触发按钮；上传/保存期间防止重复操作及关闭。

## 验证

运行 `node tools/checks/admin-ui.mjs`，使用完全隔离的模拟 API，无真实后端写入；浏览器时区刻意设为洛杉矶，验证北京时间序列化不依赖设备时区。

- 320×740、390×844、430×932、1440×900 下检查截图及页面/卡片无横向溢出。桌面延续现有居中移动端画布。
- 搜索中英文名称、状态与关键字交集、开始日期范围、刷新保留筛选。
- 编辑字段回填与 PATCH、服务端失败时保留草稿、恢复后成功；验证 14:00 北京时间仍提交为 06:00 UTC。
- 新建必填拦截与 POST，更多菜单取消/恢复、详情路由跳转；六个管理面板切换。
- 加载、无数据、无匹配、列表失败后重试、地点数据部分失败、保存成功、学生无权限；无权限时断言管理接口请求数不增加。
- 四种活动状态及跨年日期；键盘 Tab 保持在 dialog 内，Escape 返回新建按钮，减少动画设置下无装饰动画。
- 页面运行无 JavaScript 错误。主按钮白字/绿底约 4.87:1，状态深绿字/浅绿底约 5.56:1，次文字/白底约 5.72:1；页尾提示加深以满足正文对比度。
- `npm run build --prefix app` 通过，有现有大体积 bundle 提示；`npm run lint --prefix app` 无错误，保留仓库现有警告。

## 边界

- 搜索及筛选作用于管理接口当前已加载的有限列表，数量明确为“当前已加载”，未增加全库搜索、分页或总数接口。
- 正式活动仍要求时间和地点；不固定显示截图中的“时间待确认”“地点待补充”或未经业务规则判定的校外警告。
- 其他管理面板保持已有业务结构，仅公共框架和作用域主色统一；空数据面板完成切换回归，真实举报/审核写入未在本轮执行。
- 未部署、未提交或推送；未更改此前迁移中的其他代码，也未清理迁移 stash。
