## 1. 本次确认的效果与范围

**地图保留在底层，点击地点后从底部升起详情抽屉。** 地图使用现有地图实现、真实地点坐标及数据，不把参考图的插画地图替换进产品。

抽屉展示地点概要、近期活动和地点内容；点击「地点背景与校园时光」进入独立介绍页。

按用户最后确认，介绍页只保留「一张封面＋简介＋相关照片」，照片可点击放大浏览。**本轮不实现新老照片滑动对比、年代时间轴或其他时光机控件**；真实老照片可以作为普通相关照片展示，保留已有标题、年代及来源。

本说明是对[已实现的独立地点详情页](2026-11-02-地点详情页UI复刻说明.md)的后续改造方案。本轮改造以本文的地图承载方式、交互及精简介绍结构为准；不覆盖此前实施记录中的历史验证结论。

## 2. 用户操作与状态

| 操作 | 结果 |
| --- | --- |
| 点击具体地标 | 保持地图挂载，选中对应地标，抽屉从底部进入预览态；调整地图画面，让选中标记处于抽屉上方可见区域 |
| 上拖把手或允许拖动的区域 | 抽屉跟随手指，松手吸附到展开态 |
| 展开后上滑正文 | 正文向上滚动，面板停在展开位置 |
| 正文回到顶部后下拉 | 交接给面板拖动，优先回到预览态 |
| 预览态继续下拉 | 到预览位置后回弹，不靠一次误拉直接关闭；关闭以显式关闭按钮或返回操作完成 |
| 点击右上角关闭 | 抽屉向下滑出，恢复地图浏览及被遮挡的控件 |
| 点击「地点背景与校园时光」 | 打开独立介绍页；返回时恢复原地点、面板档位、内容滚动位置及地图视野 |
| 点击近期活动「查看全部」 | 进入活动列表并携带当前地点筛选 |
| 点击帖子 | 进入已有帖子详情；返回保持抽屉浏览位置 |
| 点击「在这里发布」 | 进入既有发布页，携带并实际消费当前 placeId，不能只修改 URL |

区分地点标记与帖子气泡：具体地标走地点抽屉，已有帖子气泡仍进入对应帖子详情，不把所有地图点击都改成同一动作。父级校园地标继续沿用现有聚合规则；若本轮给父级开放介绍，必须有对应真实实体与资料。

建议面板状态明确为 `closed / preview / expanded`，拖动中的位移作为临时值，不以 CSS 类或页面滚动距离暗中猜测业务状态。

## 3. 地图与抽屉的承载方式

### 3.1 地图持续存在

- 打开、展开、收起抽屉时不卸载或重建地图 SDK 实例，不重置缩放、筛选或定位状态。
- 抽屉叠在地图内容上方，地图露出区域保持可辨认；采用轻阴影分隔，不铺全屏深色遮罩。
- 抽屉打开时隐藏地图页右下角发布悬浮按钮，避免与抽屉内「在这里发布」重复或相互遮挡。
- 抽屉打开时底部主导航隐藏，关闭后恢复。展开态可隐藏地图页的大标题和分类区域，给地图和选中标记留出顶部空间；系统安全区仍然保留。
- 半屏时露出的地图可继续平移、缩放和选择其他地标；拖动抽屉时不同时触发地图手势。点击普通地图空白不关闭抽屉，避免误触。
- 选择另一地点时更新同一抽屉，重置到预览态及内容顶部；丢弃上一地点未完成的过期响应。再次点击同一地点保留当前状态。

### 3.2 高度与选中地点定位

高度按应用可用视口计算，扣除系统状态栏及必要安全区，不直接使用参考图像素。

| 档位 | 建议范围 | 表现 |
| --- | --- | --- |
| 关闭 | 面板整体位于底边以外 | 只显示原地图页面 |
| 预览 | 占可用高度约 50%–56% | 名称、地址、简介、介绍入口、近期活动优先可见，地点内容可露出开头 |
| 展开 | 占可用高度约 82%–90% | 顶部保留一段地图与选中标记，正文独立滚动 |

小高度横屏或系统大字号下，优先保证关闭、展开/收起和底部发布可用，不强求固定文字行数；允许预览态升高或正文滚动。

地图移动应以**露出地图区域的可见中心**为目标，不只是把经纬度移到整个屏幕中心。结合当前面板高度、顶栏、图钉尺寸及边缘间距计算偏移；选中标记及名称至少距抽屉上边界约 24px。无坐标时展示详情，但不编造位置或移动地图到默认点。

关闭时恢复打开前保存的地图中心和缩放；若用户在抽屉打开期间主动操作过地图，则保留其最后视野。旋转屏幕和视口变化时重算吸附点及定位偏移，不循环触发地图移动事件。

## 4. 抽屉结构与视觉

整体为米白面板、深蓝文字、橙色重点，上方大圆角，下方覆盖至安全区。模块以淡灰分隔线组织，不改成多层悬浮卡片。

| 区域 | 预览态 | 展开态 |
| --- | --- | --- |
| 顶部把手 | 居中灰色短胶囊 | 同样保留，可拖动或点击收起 |
| 名称区 | 地点名称＋浅橙分类徽标，右侧关闭 | 相同；长名称自然换行，关闭按钮不被挤走 |
| 地址 | 定位图标＋真实位置/地址 | 相同；无值时不填虚构地址 |
| 简介 | 约 2–3 行概要，必要时截断 | 可展示更长概要，完整文字在介绍页读取 |
| 介绍入口 | 橙色「地点背景与校园时光 →」 | 同样保留 |
| 地点缩略图 | 窄屏及空间不足可省略 | 概要右侧约 100×84px，小圆角；没有真实照片则省略 |
| 近期活动 | 标题与「查看全部」，空时日历图标＋「近期暂无活动」 | 同样结构，有内容时展示真实活动预览 |
| 地点内容 | 标题、排序及少量真实预览 | 标题右侧筛选、最新/近期热门、双列图文内容 |
| 底部操作 | 固定「在这里发布」 | 同样固定，不随内容滚走 |

近期活动的具体预览数量沿用接口窗口，不声称已返回全部。时间按 Asia/Shanghai 格式化，活动状态用已有定义。

地点内容优先复用现有卡片，包含真实图片/文字、作者、头像和互动状态。没有贴纸素材时不为了复刻硬编码猫图、点赞数或示例帖。双列按原始顺序排列，长文和缺图自然适配。

**排序决定：本次以参考图为准，新打开地点默认「最新」**；「近期热门」继续由服务端计算，不能在前端只对当前小窗口重排。此项为相对旧详情页默认「近期热门」的有意变更，实施和回归时需记录。

筛选沿用已有可用能力，范围要清楚：若只筛选接口返回的预览帖子，不宣称全量；「查看全部」继续携带地点进入广场。后续全量筛选由接口支持后再扩展。

### 建议视觉参数（390px CSS 宽度）

| 项目 | 建议值 |
| --- | --- |
| 背景/正文 | 米白约 `#fbfaf7` / 深蓝约 `#092752`，优先复用项目 token |
| 强调/辅助字 | 现有品牌橙 / 可读灰蓝色 |
| 顶部圆角 | 24–28px |
| 面板内边距 | 16–20px |
| 把手 | 40–46×5–6px；实际交互热区至少 44px 高 |
| 地点名 | 24–26px，粗体 |
| 分类徽标 | 11–12px，浅橙底，小胶囊 |
| 地址/概要 | 13–14px，行高 1.6–1.75 |
| 模块标题 | 17–18px，粗体 |
| 关闭按钮 | 44×44px 热区，图形约 20–22px |
| 双列内容 | 间距约 8–10px；信息列最小宽度为 0，避免长字撑出容器 |

正文底部预留「发布区高度＋底部安全区＋至少 12px」，最后一项及焦点不能被固定按钮遮住。桌面依旧使用项目居中受限宽度外壳，不让抽屉铺满整个桌面浏览器宽度。

## 5. 拖动、滚动与动效规则

### 5.1 手势交接

**展开后优先滚动正文；正文滚回顶部且本次向下拖动时，才拖动面板。** 不能把整个面板设置成禁止原生滚动的区域。

| 起点与方向 | 本次手势由谁处理 |
| --- | --- |
| 把手区域拖动 | 面板；独立于正文滚动位置 |
| 预览态正文上拖 | 先展开面板；本次先完成拖动，下一次手势滚动正文 |
| 展开态正文上滑 | 正文滚动 |
| 展开态正文下滑，scrollTop 大于顶部容差 | 正文滚动 |
| 展开态正文下拉，scrollTop ≤ 1–2px | 面板向下拖动，松手可回到预览态 |
| 正文一次滑动刚滚到顶部 | 本轮先完成正文滚动，下一次下拉才转交面板，避免中途跳动 |
| 按钮、链接、图片或水平交互区域 | 点击/相应交互优先，不因几像素移动吞掉点击 |
| 双指缩放 | 照片浏览器或地图按所属区域处理，不交给面板 |

- 识别出纵向拖动后再接管，建议移动阈值约 6–10px，忽略轻微点击抖动；水平移动占主导时不抢手势。
- 仅在确认面板拖动后捕获指针和阻止默认行为；不要给正文统一设置 `touch-action: none`。把手可单独设置触摸行为。
- 记录起始指针与面板位置，拖动位移使用相对增量，避免接管瞬间跳到手指绝对位置。
- pointercancel、失去捕获、窗口失焦时结束拖动并吸附到有效档位，不能卡在中间。
- 正文使用独立滚动容器并抑制滚动穿透；滚动面板不带动底层地图或整个页面。

### 5.2 松手与动画

- 打开、关闭、档位吸附和地图配合移动：250–350ms，建议初始 300ms，先快后慢，如 `cubic-bezier(.22,1,.36,1)`。
- 手指拖动期间面板直接跟随，不叠加 300ms transition；松手后才恢复吸附动画。
- 松手位置与方向/速度共同决定最近目标档位；建议实现时集中定义阈值并实机调试，避免不同设备手势结果相反。
- 已展开后一次下拉优先回预览，不直接跨过预览关掉面板。
- 超出边界轻微阻尼或限位，不让面板露出大块空白。
- 优先动画 transform，避免每帧重新布局地图；地图偏移在档位稳定或必要节点更新，不能每帧销毁重建地图。
- `prefers-reduced-motion` 下取消明显位移动画或显著缩短，保留最终状态与完整功能。

提供明确的「展开详情/收起详情」按钮或可点击把手，支持键盘和辅助技术；用户不必学会拖动才能使用。

## 6. 独立简介页

### 6.1 内容语义与页面组成

参考图的「北京交通大学」和四张校园照片仅用于示意排版。介绍页应始终与入口实体匹配：校园实体展示校园资料；明湖等地点入口展示该地点资料及所属校园信息，不能所有入口都显示同一份北京交通大学简介。

建议校园实体顶栏为「校园简介」，具体地点顶栏为「地点简介」；正文大标题显示真实实体名称。这是为避免名称混淆的文案约定，布局一致。

从上到下仅包含：

1. 顶栏：返回按钮＋居中标题。
2. 标题区：可选地域/校园说明、实体名称、短橙色下划线。
3. 一张横向封面：约 2.8:1，小圆角；不是轮播或对比图。
4. 简介：小标题、完整真实介绍文字，可选地址行。
5. 细分隔线。
6. 相关照片：两列图片＋简短标题；有真实年代/来源时显示辅助文字；不足四张不补示例图。

不展示近期活动、帖子流、筛选、固定发布按钮或主导航；这些留在地点抽屉。顶部系统时间、电池和底部手势条沿用 Shell/原生安全区，不重新绘制。

「简介」优先读取实体 description；若现有 history 包含有效背景资料，整理为同一简介正文中的普通段落，不再挂载时间轴或比较组件，不丢弃已有真实文字。不能拿参考图中的「这里展示校园的基本介绍…」当线上介绍。

### 6.2 页面视觉

- 背景、标题和橙色强调与抽屉一致，单列自然滚动，左右约 18–20px。
- 顶栏约 48–52px；实体名称约 26–30px；分区标题约 18–20px；正文约 15–16px、行高 1.75。
- 封面上下留白约 16–20px，圆角约 8–10px；不拉伸图片，裁切后仍保留主体。
- 相关照片两列等宽，间距约 8px，缩略图约 1.8:1，圆角约 5–6px；标题约 12–13px。
- 320px、长标题、长来源和大字号均可换行，不产生横向滚动；空间不足时照片可改一列。
- 线上真实素材不加「示例照片/照片示意」；只有实际演示素材才明确标注，来源信息不能伪造或省略为真实拍摄。

### 6.3 图片放大浏览

封面及相关照片均可点击放大；复用现有可用图片查看能力，否则拆出通用照片查看器。现有帖子媒体页若必须有 postId，不能伪造帖子 ID 套用。

- 封面作为单图打开；相关照片按当前真实数组顺序打开相册，并定位到被点击项。
- 深色全屏底、等比完整展示，提供关闭、当前序号及照片标题；来源/年代可读。
- 多图支持左右切换及明确的上一张/下一张按钮；单图隐藏无意义的切换。
- 支持手势缩放、双击放大/还原，缩放后可平移；提供按钮替代，仅双指缩放不作为唯一操作方式。
- 关闭图层回到简介页原滚动位置；恢复原缩略图焦点，不能回到地图或重载整页。
- Esc/系统返回优先关闭照片；图片加载中、失败重试和缺图各有明确反馈；失败不丢掉对应标题及来源。
- 查看器打开时锁定简介页滚动，关闭时恢复；焦点限制在查看器内，底层不响应点击和滑动。

## 7. 数据与现有代码衔接

经当前代码核对，地点已经具备详情读取与发布预选能力，地图标记点击仍主要跳转独立 `poidetail`；本说明中的抽屉、专用简介路由及独立相册尚未实现。

| 现有能力/文件 | 建议改造 |
| --- | --- |
| `MapScreen.tsx` | 地点点击改为打开/更新抽屉，管理选中 ID、档位、视野、返回恢复；保留帖子气泡原有跳转 |
| `PoiDetailScreen.tsx` / `poidetail.css` | 提取可复用的地点详情内容；独立旧路由仍可访问，避免复制两套活动、排序与请求逻辑 |

| `TimeMachine.tsx` | 不直接用于新简介页；拆出必要的真实文字/图片读取，原有其他调用不在本轮擅自删除 |
| `PublishScreen.tsx` | 复用既有 placeId 预选；登录、草稿恢复及返回过程核实未丢掉当前地点 |
| `App.tsx` / `router.ts` | 注册建议简介路由，支持直接访问、返回与抽屉状态恢复 |

可新增 `PlaceDetailSheet.tsx`、局部 CSS、`PlaceIntroScreen.tsx` 以及通用 `PhotoViewer`；文件命名可随团队约定调整，最终实施记录必须写实际文件与路由。

### 数据规则

- 现有 `ApiPlaceDetail` 有 name/category/address/description/history/photos/activities/posts/enabled 等字段；不能假定已经有独立封面或所属校园完整简介。
- 封面优先真实指定封面；现有接口未提供时，可暂取 photos 中第一张有效图片作为展示回退，同一图片不必重复占据相关照片网格。没有图片显示等尺寸米色占位，不填外部示例校门照。
- `ApiPlacePhoto` 优先 mediaId，通过现有媒体管线读取；否则使用合法 imageUrl，保留 title/yearLabel/source。无图或加载失败不移用其他地点图片。
- 校园与具体地点存在独立资料时需要明确实体关联，不能从名称包含「北京交通大学」推断所属关系；现有能力不足的字段在实施时补接口或明确留空。
- `postCount` 不当作全站累计数量；没有分页依据不显示「已加载全部」。
- 地点停用时显示说明，禁止关联新发布；服务端仍需再次校验。地点无权访问/不存在不能回退默认地点。

## 8. 路由、返回与焦点

建议约定（待实际注册）：

| 地址 | 语义 |
| --- | --- |
| `#/map?placeId=<id>&sheet=preview` | 地图上打开该地点预览抽屉 |
| `#/map?placeId=<id>&sheet=expanded` | 地图上打开展开抽屉 |
| `#/place-intro?id=<id>` | 该实体的精简介绍页 |
| `#/publish?placeId=<id>` | 已有发布页并预选地点 |
| `#/poidetail?id=<id>` | 已有兼容入口，统一使用相同数据与内容逻辑 |

- 档位变化可替换当前历史条目，避免拖动一次就增加一次浏览器返回记录；打开抽屉可增加一个可返回状态。
- 地图系统返回顺序：展开→预览→关闭→原有地图返回行为；照片查看器打开时优先关闭查看器，简介页返回抽屉。
- 直接访问简介页或旧详情页而没有地图历史时，返回到对应地点的地图预览，不能跳到无关首页。
- 抽屉内容区域标注可访问名称及展开状态；由于露出的地图仍可操作，不声明与实际行为矛盾的全屏模态。
- 打开后将焦点放到可读标题或主要控制；关闭后恢复原地图地标/等价控件焦点，不能落到隐藏按钮。
- 关闭、展开、收起、筛选和相册按钮都有可读名称、44px 热区与可见焦点；非拖动操作能完成完整流程。

## 9. 异常状态

| 场景 | 要求 |
| --- | --- |
| 地点首次加载 | 抽屉先升起并保留大致结构，显示加载反馈，不先闪其他地点资料 |
| 请求失败 | 抽屉内重试，仍可关闭，地图继续可用 |
| 切换地点/排序竞态 | 旧请求不覆盖新地点或新排序 |
| 无简介 | 简洁提示「暂无简介」，保留真实地址和照片 |
| 无封面/无相关照片 | 封面占位，相关照片显示「暂无相关照片」，不生成四张假图 |
| 无活动 | 「近期暂无活动」，仍可进入带地点筛选的活动列表 |
| 无帖子/筛选无结果 | 分别解释；热门窗口为空不宣称该地点从未有帖子 |
| 图片失败 | 同尺寸占位和重试；文字及来源仍在 |
| 未登录发布 | 沿用真实登录流程，登录后恢复当前地点，不伪造身份 |
| 地点停用/删除 | 清楚提示，禁止发布或无效跳转，关闭和返回可用 |
| 键盘、横屏和窗口尺寸变化 | 重算有效高度，不遮挡焦点及固定操作，不让面板停在屏幕外 |

## 10. 实施顺序与验收

建议先拆出可复用详情内容及数据请求，再接地图抽屉和视野偏移，随后实现简介/相册，最后验证手势、返回及多地图适配。不要以静态半屏截图代替手势实现。

验收至少覆盖：

- 地图标记点击→预览→展开→正文滚动→回顶部下拉→预览→关闭；选中点始终尽量处于露出地图范围。
- 面板拖动不带动地图，正文未到顶时下滑只滚正文；内容到顶后下一次下拉正确收起。
- 关闭恢复地图及控件；再开同一/另一地点没有旧请求覆盖、错误选中或滚动串位。
- 介绍页只有封面、简介与照片；封面和每张照片可放大、切换、缩放、关闭并恢复位置。
- 从介绍、活动和帖子返回保持原地点/面板/滚动；「在这里发布」带真实 placeId，登录与草稿恢复后仍正确。
- 320/390/430px、桌面、低高度横屏、大字号、长标题与地址、无图片/活动/帖子、停用及请求失败。
- 键盘、屏幕阅读器名称、焦点恢复、减少动效、系统安全区；底部按钮不遮挡内容。
- 使用当前启用地图实现验证定位偏移；其他受支持适配器也须验证或明确列为未测。

视觉对照建议权重：结构层级 30、布局比例/间距 25、颜色字体图标 20、组件与状态外观 15、适配与可读性 10。抽屉两档和简介页分别评审，目标各达到 80 分以上；此处是验收目标，不是已完成评分。
