# 实训项目详情页实现与验证

日期：2026-11-20。状态：复刻说明、详情实现、GitHub 资料补充与本地验收完成；未部署或更新线上数据库。

依据：[详情页 UI 复刻方案](2026-11-20-实训项目详情页UI复刻方案.md)。本轮先写方案，再实施；使用量中断后接续完成剩余浏览器验收和本地预览。

## 1. 实现结果

- 列表封面、项目名称进入 `#/project?id=项目ID`；直接体验、GitHub 链接仍保持独立。返回列表恢复原全部/人气页签与滚动位置。
- 详情提供顶部返回/分享、项目名称和简介、分类、介绍、功能图标、团队与体验提示、项目链接、真实评价列表及固定底部操作。
- `coverImageId` 继续用于列表 Logo，改为方形容器完整显示。详情新增独立的有序图片集合，图片按原比例显示，可左右切换、触摸滑动、放大、缩放、复位、Escape 关闭及失败重试。
- 没有详情图时不渲染图库，不把列表封面替代海报；没有体验网址时不渲染“立即体验”。现有正式项目未提供真实截图，所以当前本地目录不包含虚构的展示图片。
- 评价 1–500 字、登录提交、请求 ID 幂等、分页、本人或管理员删除；昵称/头像/时间来自真实账户资料。没有星级、多级回复或示例评论。
- 复用项目点赞；列表与详情重新读取服务端状态，取消和失败处理不伪造成功。登录后可返回原项目详情，适用评价草稿保留。
- 管理端分别提供“列表封面”和“详情展示图”入口，展示图最多 8 张，可排序、移除；支持维护介绍、分类、最多 4 项功能及体验提示。

## 3. 主要文件与接口

| 文件或接口 | 作用 |
| --- | --- |
| `app/src/screens/ProjectDetailScreen.tsx` / `projectdetail.css` | 详情页、图片浏览、评价、分享及固定操作栏 |
| `TrainingProjectsScreen.tsx` / `trainingprojects.css` | 列表详情入口、Logo 完整显示及返回位置 |
| `AdminProjectsPanel.tsx` | 独立图片入口、排序移除与介绍字段；上传部分失败保留成功项 |
| `App.tsx` / `LoginScreen.tsx` / `api/client.ts` | 详情路由、受控登录返回及 API 类型 |
| `server/src/projectRoutes.ts` | 详情与扩展维护字段；保留旧客户端未提交的扩展资料，媒体验证失败整体回滚 |
| `server/src/projectReviewRoutes.ts` | 评价的读取、幂等发布、删除与权限 |
| `041_project_details.sql` | 介绍字段、独立图片关系和评价表 |
| `042_project_content_enrichment.sql` | 10 个仓库对应的资料补充 |
| `GET /api/projects/:id` | 已上架项目详情，包含图库、本人点赞与评价数量 |
| `GET/POST /api/projects/:id/reviews` | 评价分页 / 登录发布 |
| `DELETE /api/projects/:id/reviews/:reviewId` | 本人或管理员删除评价 |

历史迁移文件内容保持原样。本工作区另有匿名评论相关改动与 `042_comment_anonymous`，本轮保留其内容和迁移登记；迁移使用完整版本字符串识别，不仅依赖数字前缀。
