# PR 草稿：消息、地图与浏览体验更新

整理日期：2026-11-22。范围：`zwf` 相对 `main` 的近期提交，以及当前工作区新增与修改的相关功能；提交 PR 前需将对应未跟踪文件一并纳入。本文件仅为 PR 文案，不表示已经提交、合并或部署。

## 建议标题

feat: 完善消息中心与私信，优化地图发现和校园帖子浏览体验

## PR 正文

### 改动说明

将原聊天入口升级为消息中心，集中查看帖子互动、应用公告与私信；地图页在现有地图和地标展示基础上增加可关闭的附近内容面板，同时补齐广场和详情的连续浏览。

**消息与私信**

- 点赞、收藏分别提供入口，保留“评论和@”，展示未读数量，支持分类已读和全部已读。
- 增加应用公告列表与正文页，管理员可通过管理中心发布公告。
- 从他人公开名片发起私信，同一对用户复用一个会话；未发送消息的空会话不进入消息列表。
- 会话使用用户当前昵称和头像；没有头像或加载失败时显示占位头像，匿名内容继续隐藏真实身份。
- 聊天支持历史分页、前台增量同步、发送失败重试、未读更新及拉黑；通过消息序号和幂等键避免重复发送及已读位置倒退。

**地图内容发现**

- 保留原地标标签，在右侧增加“拍照打卡”“校园故事”“最近更新”；新增筛选仅作用于底部内容面板。
- 保留当前地图底图、地标和照片标记的展示及操作方式。底部面板支持关闭按钮、下拉关闭和重新打开，并与原筛选、搜索及地点详情互斥显示。
- “附近新动态”按发布时间排序；“附近热门”按近 7 天的点赞、评论、收藏及时间衰减排序，提供不同的浏览结果。
- 增加地图内容查询接口，支持范围筛选、稳定分页及有效内容过滤。
- 纯文字帖与广场共用纸张封面组件，同一帖子保持一致的配色、正文和装饰。
- 修复地图销毁时的事件清理，并完善地图搜索范围匹配。

**帖子浏览与其他调整**

- 广场支持连续加载，详情可跨越首批 50 条继续浏览；失败可重试，返回广场恢复已加载内容及位置。
- 从地图或地点打开帖子时，按“点中的帖子 → 同地点其他帖子 → 其他地点帖子”继续浏览。
- 非匿名帖子可设置是否允许匿名评论，设置随草稿保存，服务端同步校验。
- 补齐公开作者资料、头像与名片入口，增加实训项目切换的首次提示。
- 补充 TimeMap 项目图片素材与可复用导入参数，修复 PUT 请求的 CORS 预检支持及本地远程预览脚本的进程校验。
- Web 与 Android 版本配置更新为 `1.4.3`，Android `versionCode` 更新为 `11`。

### 验证

以下为对应实现阶段已完成的验证记录；本次整理 PR 文案未重新执行全部回归。

- 前端构建、服务端类型检查与构建通过。
- 消息通知回归覆盖分类、已读快照、公告、匿名身份与权限过滤。
- 私信回归覆盖并发创建会话、幂等重试、历史及增量分页、成员隔离、限流、拉黑，以及图片和语音兼容。
- 地图回归覆盖范围与分页、最近更新与热度排序、关闭及重开面板、地图标记保持不变、纯文字封面与广场一致。
- 广场与地点浏览回归覆盖超过 50 条的续页、去重、失败重试、返回恢复和同地点优先顺序。
- 浏览器回归覆盖多个手机宽度及横屏布局；私信测试使用拦截接口，数据库测试使用本机隔离 schema。

### 上线与边界

- 新增消息相关迁移 `045_inbox.sql`、`046_direct_messages.sql`；分支还包含 `044_post_comment_policy.sql`。应按目标数据库当前迁移版本顺序补齐，先备份并检查历史私聊成员及重复会话，异常数据会使私信迁移回滚，不自动合并历史会话。
- 先部署兼容旧客户端的后端及迁移，再部署网页；版本配置更新不代表已完成 Android 打包或发布。
- “拍照打卡”“校园故事”目前保留“正在整理中”状态，管理员内容分类维护仍待实现，不从无标签帖子中自动推断分类。
- 私信采用前台轮询，尚无后台系统推送。本轮消息、私信和地图功能不以本地预览成功作为正式环境已上线的依据。
