# 地点详情页 UI 复刻说明

日期：2026-11-02

## 本次效果

以「北交大地标详情·空状态.png」为视觉参考，实现具体地点的详情页：米白背景、深蓝标题、橙色操作入口、鼠尾草绿线稿装饰，以及校史、活动、地点内容的分区排版。

页面名称、分类、地址、简介及内容来自接口。参考图中的「北京交通大学」没有硬编码到页面中；明湖、图书馆等地点显示各自资料。北京交通大学仍是地图中的父地标，地图按缩放切换父子地标的功能属于地图页后续工作，本次没有修改该逻辑。

## 数据与交互

- 校史和老照片均缺少时显示组合空状态；有资料时展示实际文字、照片及年代和来源。单独缺少校史时明确说明，图片加载失败仍保留来源信息。
- 活动为空显示「近期暂无活动」；有活动展示标题、时间与状态，点击进入详情。「查看全部」保留当前地点筛选。
- 保留原有 PLACE-002 的默认「近期热门」，与参考图默认选中「最新」存在有意差异。热门仍由服务器按近 7 天排序。
- 现有接口的 `postCount` 是当次返回条数，不能代表地点总数。热门列表为空时，额外只读请求一次最新列表，确认是否存在历史内容。确认为空才邀请用户成为第一位记录者；查询尚未完成或失败时不宣称地点从未有内容。
- 图文筛选针对当前接口返回的少量预览帖子；「查看全部」进入该地点的广场内容。全量服务端筛选与准确总数接口没有在本次 UI 任务中实现。
- 排序请求使用版本号隔离过期响应，避免快速切换后旧数据覆盖当前页面。
- 「在地图中查看」携带 `placeId`；「在这里发布」携带 `placeId` 预选地点。停用地点显示说明，不显示发布按钮。发布流程继续使用已有登录校验。
- 活动时间按北京时间显示；照片不编造年代与来源。

## 视觉差异

- 使用现有系统字体，校门和记忆插画是轻量 SVG 重绘，并非原图素材逐像素切割。
- 操作文字和发布按钮使用全局较深操作橙，以保证白字可读性；装饰使用品牌橙。
- 底部按钮固定于页面底部，内容区域独立滚动。桌面继续使用项目原有居中移动端容器。
- 不额外绘制系统状态栏；开发预览沿用现有 Shell 的模拟状态栏逻辑。
