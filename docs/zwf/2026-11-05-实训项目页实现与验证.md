# 实训项目页实现与验证

日期：2026-11-05。状态：本地实现与验证完成，尚未部署。依据：[实训项目页 UI 复刻方案](2026-11-05-实训项目页UI复刻方案.md)及用户参考图。

## 1. 已实现

- 活动标题下拉选择校园活动、实训项目；无模式参数默认校园活动。校园活动原有筛选和发布入口保留，项目模式隐藏活动筛选与浮动发布按钮。
- 实训项目显示确定副标题、全部项目/人气榜页签、点赞说明；沿用米白背景、深蓝文字、橙色操作、细分隔线及底部导航。
- 项目包含封面、名称、简介、小组人数、体验链接、点赞按钮。封面失败有占位；体验链接打开管理员录入网址。
- 点赞及取消均需登录，未登录引导现有登录流程，普通验证码登录后恢复项目模式及页签。每用户每项目唯一，可为多个项目点赞。
- 榜单按点赞数降序、固定中文名称比较、ID兜底排序；前三名金银铜奖牌，其余数字排名。两个页签共用完整项目集和权威点赞结果。
- 管理中心新增“实训项目”，支持新建、封面上传、资料修改、展示顺序和上下架。管理员写接口在服务端校验角色，操作进入审计记录。
- 新增 `032_training_projects` 迁移、项目及点赞表，唯一约束和项目行锁保证重复/并发操作的计数正确；下架不丢失历史点赞。

## 2. 页面与接口入口

| 入口 | 用途 |
| --- | --- |
| `#/activities` | 默认校园活动 |
| `#/activities?mode=projects&view=all` | 全部实训项目 |
| `#/activities?mode=projects&view=popular` | 人气榜 |
| `#/admin?panel=projects` | 管理员项目维护 |
| `GET /api/projects?view=all或popular` | 公开完整项目集，携带会话时返回本人点赞状态 |
| `PUT /api/projects/:id/like` | 幂等点赞 |
| `DELETE /api/projects/:id/like` | 幂等取消 |
| `GET /api/admin/projects` | 管理员读取项目（含未上架） |
| `POST /api/admin/projects` | 创建项目 |
| `PUT /api/admin/projects/:id` | 更新项目完整资料及展示状态 |

前台一次获取本班完整项目集，切换页签在本地排序；服务端同样提供榜单顺序。点赞成功后读取服务端完整结果，前台通过请求版本与点赞更新版本避免旧响应覆盖新状态。封面复用现有公开图片上传流程 `purpose=activity`，项目维护时校验媒体为公开图片。

在接入迁移时发现原 `db.ts` 有重复的 `030_user_profiles` 条目及多余的数组闭合符，已修正，以便迁移清单和后端构建正常工作；未修改历史 SQL 内容或校验和。
