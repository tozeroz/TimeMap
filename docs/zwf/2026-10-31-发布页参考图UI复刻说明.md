# 发布页参考图 UI 复刻说明

日期：2026-10-31。适用模块：TimeMap 帖子发布页（`#/publish`）。文档归属：zwf 个人模块工作记录。

## 目标与参考

本次依据提供的《校园回忆发布页.png》和《校园湖畔回忆编辑页.png》，实现同一发布页的两种状态：未添加照片时的回忆表单，以及添加照片后的图片文字编辑界面。主要操作仍为关联校园地点后发布文字或照片。

参考图用于确定布局、配色和控件样式；照片来自用户实际选择的图片，不将参考图中的示例湖景内置为帖子内容。页面继续使用现有 React、CSS、Canvas 和相机封装，没有新增运行依赖。

## 两种界面状态

### 未添加照片

- 顶栏显示“写一段回忆”，右侧沿用发布条件校验和加载状态。
- 显示“把这一刻，留在校园里。”两行标题和橙色短线。空白态标题使用宋体字体栈，呼应第一张参考图。
- 将原本有边框的地点下拉框改成地点图标、提示/地点名、必选标签和箭头组成的一行。底层仍使用原生 `select`，保留原有地点数据及键盘选择能力。
- 正文使用无边框输入区，字数统计右对齐，保留 500 字校验。
- 添加照片区域使用绿色虚线框、橙色照片图标及辅助文案，底部增加小径和嫩芽装饰。

### 添加照片后

- 标题切换为紧凑的系统黑体布局，正文区域收紧，将空间留给照片与编辑工具。
- 照片完整显示并保留比例，不为追求参考图的固定比例裁切用户图片。
- 图片上方提供“图片编辑”和更多操作入口；下方提供添加文字、生成贴纸、更换、删除操作。
- 点击添加文字或图片编辑可展开文字面板；点击完成隐藏面板和选中框，图片文字继续保留。
- 底部根据当前所选地点提示这段回忆发布后的地图归属。

## 图片文字编辑实现

`ImageText` 增加以下可选字段，旧草稿缺省时按默认值处理：

```ts
style?: 'simple' | 'handwritten' | 'outline'
scale?: number       // 0.5–2
rotation?: number    // 角度
```

文字仍限制为 50 字。原有 `text`、`color`、`size`、`x`、`y` 字段保留；既有草稿和调色值可继续读取。默认字号比例有调整，因此旧草稿的视觉字号可能与改版前略有不同。

- 简约：无衬线字体，提供轻量对比描边以改善照片上的可读性。
- 手写：使用 `KaiTi`、`STKaiti`、`Kaiti SC`、`cursive` 字体回退链。
- 描边：增加描边宽度。
- 工具面板显示白、黑、珊瑚橙、鼠尾草绿四个色块；保留旧颜色值的导出兼容。
- 通过选中框内部拖动文字，通过角上的控制柄缩放，通过底部旋转柄旋转；大小和角度滑块提供另一种操作入口。
- 键盘聚焦移动区后可用方向键移动；聚焦缩放柄后用上下键调整；聚焦旋转柄后用左右键每次旋转 5 度。

预览文字使用透明 Canvas，导出时在原图 Canvas 上使用相同的排版、换行、字体、边界和旋转计算。选中框和控制柄只属于编辑界面，不会被合成到发布图片中。旋转后的外接边界参与位置限制；极端宽高比或多行文字会自动缩小以保持完整显示。

新增编辑属性会随现有 `imageText` 对象保存进本地草稿，无需新增数据库字段。发布仍上传合成后的图片，沿用原有地图媒体与帖子媒体的处理方式。

## 保留的业务与交互

- 地点必选，正文或照片至少有一项，正文最多 500 字、图片文字最多 50 字。
- 拍照/相册、生成主体贴纸、白色描边、确认采用贴纸、恢复原图。
- 发布中防止重复提交、失败保留内容、未确认提交的重试流程。
- 退出编辑时保存草稿或放弃编辑，重新进入后恢复草稿。
- 弹出面板的焦点管理、Tab 循环、Escape 关闭，以及减少动效设置。

## 验证结果

- `npm run build --prefix app`：通过。构建仍提示主包超过 500 kB，此次未进行代码拆包。
- `npm run lint --prefix app`：无错误，仓库已有的 React effect/Fast Refresh 警告仍保留。
- 浏览器检查：320×812、390×844、1440×900 下的空白态和可发布态，无文档横向溢出；另在 390×950 查看完整编辑面板，窄屏下颜色和样式选项可换行。
- 校验和状态：正文超限、图片文字超限、发布禁用、加载宽度稳定、地点加载失败及重试、模拟发布失败保留正文。
- 图片编辑：相册文件选择、样式和颜色切换、方向键移动、鼠标拖动、键盘缩放/旋转、完成后隐藏选中框、重新打开编辑。
- 草稿：实际写入隔离浏览器的 IndexedDB，恢复后检查样式、缩放和旋转值。
- 导出：12 组图片宽高比与旋转角度组合的文字边界检查，旧字段草稿 PNG 导出，以及 50 字上限校验。
- 可访问性：可见焦点、地点控件焦点提示、正文标签/错误关联、面板键盘循环和减少动效；模拟照片权限错误时保留错误说明和相册恢复路径。

截图、检查脚本、导出检查结果和原始日志位于 `docs/local/publish-reference/`，属于被 Git 忽略的本机验证产物，不随本说明提交。测试用照片是本地生成的测试图形，不是内置产品素材。

## 差异与未验证事项

- 字体依赖设备本地可用字体；没有打包中文字体文件，宋体与手写效果无法保证跨设备逐像素一致。原生安全区、状态栏和系统底部手势条仍由既有 Shell/设备处理。
- 为保持可读性，主操作白字继续使用已有的深橙底色，辅助文字也比参考图更深；橙色装饰仍使用品牌橙。
- 大小/旋转滑块是参考图之外补充的可访问操作入口。编辑区允许滚动，手机键盘打开时的实际布局仍需真机确认。
- 浏览器验证中的 API 均被本地拦截，没有向真实后端发帖，也没有调用付费抠图供应商。真实抠图返回、真实发布成功后的完整链路、Android 相机/存储权限弹窗和多设备字体效果未在本轮验收。
