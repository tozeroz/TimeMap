# 消息撤回

实施日期：2026-11-22。支持私聊和群聊中的文字、图片和语音消息。

自己的已发送消息下方提供「撤回」按钮，确认后双方显示「消息已撤回」。不设发送后的时间限制，不能撤回其他人的消息。撤回不能消除对方此前看过、下载或截图的内容。取消和接口失败均保留原消息，失败可重试。

## 实现

- `POST /api/threads/:id/messages/:messageId/revoke`：必须登录、属于该会话且为消息发送者。原子更新 `deleted_at`，重复调用保持同一撤回时间。保留消息 ID、序号、幂等键与媒体引用，不新增消息。
- `POST /api/threads/:id/messages/revocations`：成员提交至多 200 个已加载消息 ID，返回其中已撤回的 ID。聊天页在已有前台轮询中分批同步，覆盖已翻出的旧消息；仅靠 `afterSeq` 无法发现旧消息撤回。
- 客户端收到撤回后清空显示正文与附件，卸载图片／语音组件。已确认撤回的消息不被迟到的消息查询恢复。
- 现有媒体授权谓词拒绝读取已撤回消息的附件；现有会话摘要和未读统计遵守 `deleted_at`。消息列表仍按原前台刷新周期更新。
- 使用已有字段和授权函数，无新增数据库迁移。
