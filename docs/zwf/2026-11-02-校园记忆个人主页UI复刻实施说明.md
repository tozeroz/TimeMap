# 校园记忆个人主页 UI 复刻实施说明

日期：2026-11-02。适用模块：`#/me`。状态：本地实现完成，未提交、未部署。

## 结果与参考

按[复刻方案](2026-11-02-校园记忆个人主页UI复刻方案.md)实现暖米白个人主页：居中桃色首字头像、叶片 SVG、昵称、描边编辑按钮、菜单／分享／消息工具栏；「我的发布 / 我的收藏」原地切换；下方照片和文字两种卡片组成双列内容墙，底栏以橙色标记「我的」。移除个人页原有语音提示、整块入口列表和悬浮发布按钮。

以 80% 以上的主要视觉元素还原为目标，已逐项对照结构、配色、头像、叶片、标签、卡片及导航。390px 测试首屏的标签底边约在 y=232px，参考图按同宽缩放约为 y=229px。这个对照说明布局比例接近，不是像素相似度评分。系统字体、真实帖子照片及设备安全区会与参考图产生差异。

## 数据与功能

- 新增 `getMyIdentity()` 保留身份请求的 HTTP 状态；原 `me()` 兼容返回 `SessionUser | null`，现有调用方继续可用。区分 401 与网络／服务异常。
- 发布通过当前权威身份的 `authorId` 查询；收藏复用现有接口。两类集合各自保存请求结果及加载状态；原始帖子排序不被客户端重排。
- 卡片使用真实正文、媒体、地点、日期和点赞数，不将截图昵称与数字硬编码进生产组件。媒体失败保留文字与地点，贴纸保留透明容器。
- 瀑布流采用 ResizeObserver 测量卡片，分别累计左右列的网格行位置；DOM 保持源数据顺序。日期按北京时间显示，跨年补年份。
- 活动收藏在收藏标签内保留入口；独立发布、收藏页面仍存在。设置、清缓存、管理端与退出登录移入菜单，服务端权限控制保持不变。
- 菜单支持 Escape 和焦点约束；清缓存使用原生 dialog，取消不清数据，关闭后焦点回菜单。
- 分享调用系统分享，不支持时复制当前站点入口。用户取消分享不显示失败。
- 标签和按用户区分的滚动位置只保存浏览元数据，不把私人帖子缓存进 sessionStorage。退出后清空当前组件中的身份与集合。

## 验证及限制

- 前端 `build`、`lint` 通过。项目原有其他页面的 lint 警告和大包体积提示仍存在；本次修改的个人页、菜单和导航定向 lint 无警告。
- 渲染检查覆盖 320×812、375×812、约 390×693、1440×900。390 请求视口的最终截图为 390×692，记录以实际产物为准。桌面保持 430px 居中，无页面横向溢出。
- 使用实际组件及本地拦截的测试响应验证有内容、加载、空内容、503、401、长昵称、图片失败；测试昵称与文字仅存在被忽略的临时夹具中，照片使用公开帖子媒体样本。
- 验证标签键盘切换、活动收藏可达、菜单焦点回环、Escape、清缓存取消、列表重试、滚动位置恢复（140px）和测试会话退出后私人卡片清零。
- 实际远程接口页面能显示未登录状态；没有使用真实账号修改资料、发帖或写入远程数据库。系统分享面板完成流程与原生 Android 本轮未实测。
- 视觉证据和夹具源码保存在被 Git 忽略的 `docs/local/me-reference/`；临时网页入口在检查后移除，生产页面不包含测试身份或帖子数据。
