# 地图页参考图复刻方案

日期：2026-10-31。范围：地图首页参考图调研；本轮不修改产品页面和接口。

参考：《北交大时光坐标地图.png》。判断基于当前本地源码与下方地图官方文档，未验证线上账号的地图样式配置。

## 结论

推荐先保留真实地图，完成界面、标记及视野数据的改造；如需参考图的逐棵树木、建筑阴影和纸面质感，再单独制作并校准校园插画地图。页面控件和照片标记有现成基础，手绘地图是主要的不确定成本。

## 底图路线比较

### A：真实地图与自定义配色（推荐先做）

保留当前腾讯 GL → 高德 JS → Leaflet 栅格 → 离线自绘的降级链。以现有实际能稳定加载的 provider 为首轮验收对象，将地图调整为浅灰楼块、浅绿植被和淡蓝水面，再叠加自定义照片与文字覆盖物。

高德官方 JS API 1.4 文档支持通过 `mapStyle` 应用模板或自定义样式，与仓库当前加载的 1.4.15 版本相符。腾讯样式需要另行核对账号和样式配置，本轮没有验证其控制台。

这种方式能接近参考图的颜色和空间层次；无法仅靠配色自动生成图中的逐棵树冠、手绘阴影或精确纸面纹理。此结论是对参考图与样式能力的技术判断，不是对特定模板效果的实测。

### B：独立校园插画与地理校准

先准备没有照片、气泡、按钮和标记的干净校园底图，确认建筑道路关系，再为其提供经纬度边界与多个参考锚点。通过地图图片覆盖层或切片层实现缩放、拖动和标记投影。

Leaflet 的 `ImageOverlay` 可以把图片绑定到指定经纬度边界，但简单矩形边界不能自动修正图稿自身的旋转、透视、非线性变形。需要先将图稿校正到所用地图投影，并统一数据坐标系；定位坐标转换需避免重复转换。

验收至少比较南门、思源碑、图书馆、明湖等控制点，在不同缩放下检查落点误差。当前离线 SVG 的投影尚未校准，而且刻意不显示权威地点标记，不能直接给它换张漂亮图片就当成精确地图。

该路线最接近参考图，但图稿制作、校准和校区扩展成本较高。参考截图已含遮挡物，也没有地理边界，不能直接当干净底图使用；生成式插画只能作为美术草稿，不能直接承诺建筑位置准确。

## 数据与交互设计

1. 扩展 `MapHandle`：视野边界、经纬度到容器像素投影、视图变化订阅；保持各在线 provider 的行为一致。
2. 当前 `/api/posts` 有 `LIST_LIMIT = 50`，地点列表有 200 条上限。地图目前以地点列表结合有限帖子列表选代表帖，无法保证每个地点取得正确封面，也不能由返回条数推出全部记录数。
3. 建议新增专用地图读取接口，按视野边界、学校/校区、分类查询，返回可见地点、代表帖封面/点赞和区域公开记录总数；文字弹幕候选独立返回或明确分组。接口名和字段在实现时确定。
4. 区域记忆数建议定义为当前分类与学校范围内、地点坐标落在视野中的公开帖子数量。聚合数字另定义为聚合的地点数，点赞数字仍是代表帖点赞数。
5. 照片卡片、普通地点标签、文字气泡分层渲染；低缩放聚合/隐藏部分卡片，高缩放展开，并按优先级避免重叠。不从截图推断排序规则，需明确采用最新代表帖或其他规则。
6. 图片打开代表帖，地点标签打开地点详情，聚合点放大或展开；现有点击分流已有基础，应保留。
7. 地理锚定文字气泡与滚动弹幕不是同一功能。图中气泡有地点锚点，截图无法证明其滚动方式；如保留“弹幕”命名，需要实现可见区域候选、轮播/滚动规则、密度控制及可用开关，不能只隐藏文字卡片冒充完整弹幕。
8. 视野更新合并到动画帧，网络查询在移动结束后短暂防抖并丢弃过期结果；标记数据刷新不应销毁地图实例并重置视角。当前 provider 的初始化 effect 依赖 markers，实施时需拆分实例创建和覆盖物更新。
9. 发布成功回到地图时仍高亮并定位对应地点，返回详情后保持视角；加载、无记录、部分数据失败、定位拒绝及底图失败分别反馈。

## 实施顺序与工作量

以下为熟悉仓库的一名前端开发者、具备后端配合情况下的粗略人日，不是交付日期承诺。

| 阶段 | 内容 | 估计 |
| --- | --- | --- |
| 1 | 头部、分类、浮动工具和底部导航视觉；统一照片标记样式 | 1–2 人日 |
| 2 | 视野接口、统计口径、覆盖物更新、气泡候选与开关 | 2–4 人日 |
| 3 | 聚合、避让及拖动/缩放性能；多 provider 和手机回归 | 1–3 人日 |
| 可选插画路线 | 插画资产、地理校准、图片层/切片及缩放验收 | 在上述基础上增加约 5–10 人日，取决于图稿质量 |

推荐第一阶段先做可操作的真实地图样板，再继续视野内容能力。暂不把换地图引擎、SDK 升级、美术底图制作和 UI 改版混在同一个变更里。

## 后续验收

- 窄屏/常规手机/桌面检查地图可视面积、按钮遮挡及文字长度；不复制系统状态栏与手势条。
- 平移和缩放后照片、标签、气泡锚点不漂移，聚合可展开，拖动起手不误开帖子。
- 分类、学校、视野统计和弹幕候选使用相同可见性口径；数量大于 50 条时仍正确。
- 清晰区分无记录和请求失败；无未读时不显示消息红点。
- 定位拒绝、弱网底图降级、帖子图片失败有恢复路径；保留地图来源标识和真实比例尺，不把腾讯字样画到高德底图上。
- 保留真实发布回跳、详情返回和视角恢复；视野统计请求不在每帧发出。
