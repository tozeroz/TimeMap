# 校园广场连续加载

修复广场最多加载 50 条、详情只能刷完这 50 条的问题。现在列表接近底部时继续加载，详情接近当前列表末尾时预取下一页，直到全部公开回忆读完；没有更多时显示结束，不循环旧内容。失败保留已有内容和游标，支持重试。返回广场保留当前会话已经加载的帖子与滚动位置。

帖子列表接口新增可选 `paginate=1` 和 `cursor`，每页 50 条。最新按发布时间和 ID 倒序，以数据库原始时间精度做游标分页。热门首批沿用现有推荐排序，后续按最新顺序补全剩余内容，并排除首批已推荐的 ID，避免推荐池导致旧回忆不可达。筛选条件在每页查询中持续生效；切换筛选或排序时重新开始，过期响应被丢弃。未请求分页的旧调用方维持原接口行为。

验证：前后端构建及服务端类型检查通过。数据库回归覆盖 127 条公开帖子、下架排除、超过两页、热门与最新均无重复无遗漏、相同微秒时间戳、非法游标。浏览器回归覆盖广场续页、失败重试、详情跨越第 50 条和返回恢复列表。

无需数据库迁移；尚未部署线上。
