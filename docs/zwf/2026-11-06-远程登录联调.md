# 远程登录联调

日期：2026-11-06。状态：可写远程连接已启动，等待用户完成真实手机号登录测试，再决定前后端发布。本轮没有部署或重启线上服务。

## 连接方式

- 网页：`http://127.0.0.1:5180/`；本地网关：`http://127.0.0.1:3003/`。
- SSH 隧道连接原有线上数据库及 nginx。数据库凭据只在网关内存读取，不写入本地配置或日志。
- 验证码获取、校验及既有业务请求转发到正式后端；实训项目使用当前项目路由，并校验同一线上数据库中的真实会话、角色、过期和撤销状态。
- 网关默认仍是只读模式；显式使用 `tools/start-remote-preview.ps1 -Writable` 才启用可写联调。此模式中的登录、点赞和维护会影响真实远程数据，不运行数据库迁移。
- 修复停止脚本将进程开始时间与 JSON 时间直接作字符串比较的问题，改为 UTC ticks 对比，避免旧只读进程残留占用 3003 端口。

## 本轮修正

- 网关支持正式认证请求、JSON/表单内容转发及跨域 POST、PUT、PATCH、DELETE。
- 项目接口识别真实 Bearer 会话；无会话点赞返回 401，非管理员不能维护项目。
- 后端正式构建补齐 `PUT` 的 CORS 允许方法，防止项目点赞上线后跨域失败；此修正尚未部署。
- 登录页对只读模式的 405 给出准确说明，避免再次误报成网络故障。
