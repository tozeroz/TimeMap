负责人：zwf。最近更新：2026-11-02。适用范围：个人负责模块的分析、草稿和开发记录。

本目录按[文档管理约定](../public/文档管理约定.md)建立。它不会被整体忽略，有团队协作价值的资料可以提交 Git；纯本机内容放在 `docs/local/`。

## 存放规则

- 模块分析、方案草稿和代码阅读笔记放在对应模块子目录，注明日期、适用代码或提交、已确认事项和待确认事项。
- 工作记录使用 `YYYY-MM-DD-主题.md` 命名，避免“最终版2”等重复文件名。
- 正式需求、接口、数据库字段和维护说明经确认后整理到 `docs/public/`，在个人笔记中链接正式版本。
- 正式测试报告与必要证据放在 `docs/test/`。
- 临时截图、原始输出、日志、AI 对话及无需共享的草稿放在[本地资料目录](../local/README.md)，不要提交。
- 不保存服务器私钥、真实 API Key、密码或登录令牌。
