# 校园广场 UI 复刻实施说明

日期：2026-11-02  
页面：`#/campus`  
参考：`时光坐标校园广场界面.png`

## 已实现

校园广场改为米白背景、深蓝标题、橙色选中态和两列错落卡片。排序、筛选、帖子详情、作者主页、点赞、消息与发布沿用已有接口和路由。

- 页头改为「校园广场」，保留学校/校区浏览及消息入口。
- 热门/最新使用橙色文字和短下划线，地点筛选入口增加定位图标。
- 照片卡片将正文、地点、作者与点赞放到图片下方的白底区域。
- 贴纸卡片依据接口 `imageMode` 显示「主体贴纸」角标和浅绿背景；使用帖子首图，不拿地图专用媒体替代帖子配图。
- 纯文字卡片使用浅杏色纹理、局部楷体回退和轻量叶片线稿。真实正文保留为文本，长文截断后进入详情查看。
- 头像、地点和点赞各自排布；帖子使用真实链接，作者与点赞是独立按钮。
- 广场底栏采用与活动页一致的暖色背景、橙色选中态；保留已有悬浮发布按钮及底部安全区。

## 数据与可靠性

- 完全使用实际帖子内容、媒体和服务端互动结果，没有插入参考图中的演示帖子。
- 点赞请求进行中禁用该帖按钮；失败显示提示，保持原状态。未登录点赞继续进入登录流程。
- 排序/地点变化后丢弃过期请求；加载过程中如保留旧卡片，会显示「正在更新回忆」。
- 请求发出后发生的成功点赞结果会合并到随后返回的列表，防止较早列表响应覆盖刚完成的互动。
- 热门空列表提供「查看最新」，不再声称整个校园从未有人发帖。
- 列表末尾改为「已加载 N 条回忆」，不把服务端有限条数说成完整列表。
- 图片失败时保留正文、地点、作者和点赞，并显示中性占位。
- 保留现有离线快照说明和错误重试流程。

## 与参考图的有意差异及范围

1. **学校副标题**：显示「学校与校区」，保留现有资料面板。当前列表只传排序和地点条件，学校归属筛选没有接通，不能仅改校名就承诺帖子已按学校隔离。
2. **真实素材**：照片、透明贴纸、头像受接口实际数据影响。头像沿用现有默认头像生成方式；没有为复刻随机补入真人头像或自动触发抠图。
3. **贴纸展示**：界面能区分图片模式，但若后端帖子首图实际仍为普通照片，CSS 不会把照片变成透明主体。需要发布流程提供正确的贴纸成品。
4. **双列顺序**：接口索引 0、2、4…进入左列，1、3、5…进入右列，保留视觉上的排序交错；键盘和 DOM 按左列、右列顺序浏览。未实现按实时最短列分配的复杂瀑布流。
5. **父子地标**：未修改数据库、父地标聚合、地图缩放切换或地点筛选接口语义。
6. **公共面板**：沿用已有学校与地点选择面板，未在本次卡片改造中重构其键盘焦点管理。完整分页、真实用户头像与学校内容隔离仍是后续独立工作。
