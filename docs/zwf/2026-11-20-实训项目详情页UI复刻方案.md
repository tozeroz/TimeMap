# 实训项目详情页 UI 复刻方案

日期：2026-11-20。参考：用户提供的项目详情截图。适用：实训项目列表点击后的详情、详情图片与评价、后台项目维护。本方案先于实现编写；本轮随后按方案实现并另行记录验证结果，不将参考图中的评论或票数写入正式数据。

状态：已完成本地实现与验收，见[实现与验证记录](2026-11-20-实训项目详情页实现与验证.md)。尚未部署线上。

## 1. 已确定文案与入口

| 位置 | 目标 |
| --- | --- |
| 顶部 | 返回、居中“项目详情”、分享 |
| 项目信息 | 真实项目名称、一句话简介、项目分类及“实训项目”标记 |
| 介绍区 | 橙色短竖线 + “项目介绍”；完整介绍与最多 4 项核心功能 |
| 补充资料 | 团队信息、体验提示、GitHub“项目链接”；没有资料的项目不编造内容 |
| 评价区 | “用户评价（实际数量）”、写评价、提示“体验怎么样？分享感受或提个建议吧。” |
| 底部操作 | 点赞及数量、写评价、橙色“立即体验 ↗” |
| 无体验网址 | 隐藏“立即体验”，保留点赞、写评价及正文项目链接；GitHub 不冒充体验地址 |

列表中的封面和项目名称进入详情；“体验项目”与“项目链接”仍直接打开各自网址。普通列表行不新增整行点击，避免与点赞、外链产生冲突。详情采用独立路由 `#/project?id=项目ID`，返回原全部项目或人气榜及滚动位置。直接访问详情时，无列表历史可返回实训全部项目。

      评价正文

采用现有米白 `--c-bg`、深蓝 `--c-text`、蓝灰辅助文字和橙色 `--c-primary`。内容以留白和 1px 细分隔线组织，不增加嵌套厚边框卡片。区标题前使用橙色短竖线；评价头像、昵称、时间与正文呈连续列表。详情页以固定操作栏替换主底部导航，列表页保留原导航。

手机左右留白约 20–24px，320px 可降至 16px；项目名约 27–30px 粗体，区标题约 21–23px，正文约 15–16px、行高 1.65。底栏按钮最小触控区域 44px，适配原生安全区。320px 下底部三项可收紧文字间距，不遮挡正文或横向溢出。桌面继续使用现有居中移动端画布。

截图的“校园生活”、地图探索/记忆发布/校园活动属于 TimeMap 示例，其余项目以各自资料展示。“以上为项目展示示例”“示例评价”和 128 赞不写入正式产品。分享成功、复制失败等给出明确反馈。

## 3. 两类图片分别维护

| 项目 | 列表封面 | 详情展示图 |
| --- | --- | --- |
| 目的 | 快速识别项目 | 展示实际界面、海报与亮点 |
| 数据 | 现有 `coverImageId` | 新增独立、有顺序的展示图集合 |
| 容器 | 正方形缩略图 | 随原图比例展示；横图、竖图、不同尺寸均保留完整画面 |
| 缩放 | `object-fit: contain`，留白承载透明或非正方 Logo | 宽度受内容区约束，高度自适应，禁止强制横幅裁切 |
| 多图 | 单张 | 本期建议最多 8 张，可上传、排序、移除 |
| 点击 | 进入详情 | 打开放大浏览，支持上一张/下一张、关闭与键盘操作 |
| 未上传 | 原有无封面占位 | 隐藏整个图库，不挪用列表封面、不保留空白横幅 |
| 上传失败 | 保留旧图 | 保留已成功的图片与顺序，显示具体失败项供重试 |

详情图库使用水平滚动与吸附，提供按钮和张数，不仅依靠滑动手势。轮播高度随当前图片比例调整，竖海报完整显示并允许页面正常纵向滚动。放大层使用独立全屏/对话框，图片限制在视口内完整显示；提供缩放和复位，Escape 可关闭，焦点返回原图片。

后台将入口明确命名为“列表封面”和“详情展示图”，两个控件互不覆盖。封面更新不修改详情图；详情图更新不替换列表 Logo。公开图片沿用既有媒体上传与权限校验，不直接把网页截图热链当作本地上传媒体。

## 4. 交互与权限

### 项目介绍与 GitHub 扩充

- 重新读取各项目公开 README，补充介绍、最多 4 项核心功能、体验提示与分类；记录来源 URL、文件 SHA 和核对日期。
- README 的设计目标与已实现功能区分表达，不把开发计划写成完成承诺；不复制仓库内给自动化工具的操作指令。
- 名称、团队编号、人数、评分、头像和评论均不推测；没有明确资料则继续留空。
- 仅为确认的直接可体验网址显示体验操作；本地启动地址不录为线上体验网址。保留管理员后续修改，不以初始化覆盖既有封面、图库或点赞。

### 点赞与评价

- 复用现有项目点赞，列表、详情、人气榜按服务端结果同步；每人每项目一次，可取消，可给多个项目点赞。
- 评价使用简单文字，本期 1–500 字，不加星级、多级回复和评论点赞。默认按发布时间倒序，ID 兜底，分页继续加载。
- 写评价需登录；记录项目详情回跳，返回后保留适用草稿，由用户明确提交，不自动补发。评价提交携带请求 ID，重复点击或网络重试不会创建重复评价。
- 展示真实用户昵称、头像和时间；无头像使用统一占位。当前无评价时显示“还没有评价，来分享你的体验吧”，不生成示例评论。
- 用户可删除自己的评价，管理员可删除不合适的评价；服务端校验身份，普通用户不能代删。公开数量随删除更新。
- 项目下架后详情、评价读取和新点赞/新评价均不可用，显示项目已下架或不存在；本期不永久删除项目。

### 底部、返回与分享

- 底栏始终可见，不随正文滚走；正文保留足够底部空间。写评价展开可访问表单；软键盘下仍能滚动到提交与取消。
- 返回恢复原列表模式、页签及滚动位置；直接详情链接有明确回到全部项目的路径。登录回跳扩展受控目标，保留现有活动投稿回跳。
- 分享当前详情链接，优先系统分享，失败或不支持时提供复制与手动复制，不把用户取消分享当成错误。

## 6. 状态与验收

| 状态 | 显示与恢复 |
| --- | --- |
| 加载 | 稳定的骨架和进度，避免展示其他项目旧资料 |
| 详情失败 | 明确提示与重试；返回列表仍可使用 |
| 项目下架/不存在 | 项目不可用提示，不展示可操作底栏 |
| 无详情图 | 无空横幅，直接显示项目基本信息、介绍和评价 |
| 某图损坏 | 当前图可重试/占位，其余图片与正文仍可用 |
| 无评价 | 真实空态和写评价入口，数量为 0 |
| 未登录/过期 | 进入登录并保存受控项目回跳与适用草稿，不伪装提交成功 |
| 提交/删除失败 | 保留输入，允许重试，计数不伪造 |
| 无体验网址 | 底栏只显示点赞与评价；正文保留已有项目链接 |

实施验收：320×740、390×844、430×932、1440×900；正方 Logo 不被裁切，横图/竖图完整展示，多图切换与放大可用，缺图无空位；键盘焦点、Escape、触控区域、对比度及减少动画设置正确；固定底栏不遮挡最后一条评价。验证实际路由、返回/登录回跳、点赞同步、评价权限/幂等/分页/失败恢复、管理员图片独立维护与数据重载。

本方案不授权把参考截图中的海报、头像或评论作为真实项目数据发布；未获取真实展示图片的项目先保留无图库状态，管理员可后续上传。
