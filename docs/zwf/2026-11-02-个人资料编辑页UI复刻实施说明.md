## 页面与功能

米白背景、深蓝标题与正文、浅桃色首字头像、叶片装饰、橙色相机入口、个人信息与校园信息分组、细分隔线及底部橙色保存按钮按参考图实现。

| 区域 | 当前行为 |
| --- | --- |
| 头像 | 点击相机或头像选择 JPG/PNG/WebP，最大 5MB；上传后完整保存才更新用户关联，可移除头像 |
| 昵称 | 编辑弹窗，trim 后非空，最多 40 个字符 |
| 个人简介 | 多行编辑，最多 160 字；空字符串清除 |
| 学校 | 展示服务端配置的当前服务学校，不允许用户修改，不代表学籍认证 |
| 校区 | 从该校真实候选中选择，可选“不填写” |
| 学院 | 从已有学院表选择，可选“不填写”；列表为已有子集，不声称完整 |
| 年级 | 输入四位入学年份，1900–2100；留空清除，不代表生日或年龄 |
| 保存修改 | 批量提交全部资料，成功使用服务端返回值更新；返回“我的”显示新头像、昵称和简介 |

头像是公开媒体，简介及校园选择为用户主动填写的资料。本次没有把校区、学院、年级扩展到他人公开身份接口；完整资料只通过本人接口读取。详见[后端与数据库实施说明](2026-11-02-个人资料后端与数据库实施说明.md)。

## 交互与数据

- 页面从本人资料接口读取真实值及校园候选；未登录提供登录入口，网络或服务版本错误提供重试。
- 编辑弹窗中的“完成”只修改本页草稿，底部“保存修改”才调用 PATCH；刷新前未保存内容不承诺恢复。
- 字段空值可以清除；学校只读。校区与学院的校属、头像上传者身份由服务端重新校验。
- 上传及保存中防重复，并阻止误离开；有未保存资料时离开确认。
- 上传失败保留原头像；保存失败保留所有草稿，不能回显假成功或更新会话缓存。
- 成功后更新现有会话缓存；“我的”仍从身份接口读取权威值，头像加载失败回退首字。
- 昵称/简介/选择器使用有标签的原生 dialog；Escape 可关闭并归还焦点。全局可见焦点与减少动效设置保留。
